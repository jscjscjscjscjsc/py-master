# 🐍 PyMaster — Python 编程学习平台

## 功能特性

- 🔐 用户注册/登录系统
- 📚 9章Python基础课程（40+知识点详解）
- ✏️ 18+练习题（含答案和详细解析）
- 🎨 交互式漫画讲解（中文语音播报）
- 🧠 思维导图大纲（XMind风格）
- 💻 在线Python代码练习场
- 🤖 JJ老师AI助教（DeepSeek驱动）
- 📊 PPT课件链接
- 📈 学习进度追踪
- 🎮 赛博朋克风格UI

## 快速开始

### 方式1：双击运行（推荐）

1. 双击 `启动PyMaster.bat`
2. 浏览器会自动打开 `http://127.0.0.1:5000`
3. 注册账号 → 开始学习！

### 方式2：命令行运行

```bash
pip install -r requirements.txt
python app.py
```

## 首次使用

1. 打开后先点击「注册」标签
2. 输入用户名（≥3字符）和密码（≥6字符）
3. 注册成功后登录
4. 进入学习仪表盘，选择章节开始学习
