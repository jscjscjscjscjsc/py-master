02. 4.1 索引与切片 ▼

4.1.1 概念认知：字符串是有序的字符序列

字符串不是"一团文字"，而是一个有序的字符序列——每个字符都有编号（索引），从 0 开始数。

索引：  0   1   2   3   4   5
字符：  P   y   t   h   o   n

4.1.2 语法掌握：正向索引与负向索引

代码案例 4.1：索引访问（✅ 正确）

python
s = "Python"
print(s[0])
print(s[3])
print(s[-1])
print(s[-2])

运行结果：

P
h
n
o

讲解：

  • s[0] 是第一个字符；
  • 负数索引从右往左数：s[-1] 是最后一个字符，s[-2] 是倒数第二个——取"末尾字符"时比正数索引方便得多。

交叉验证：索引越界

❌ 易错：

python
s = "Python"
print(s[6])

实际报错：

IndexError: string index out of range

讲解："Python" 有 6 个字符，合法索引是 0~5，s[6] 越界。IndexError: string index out of range 是新手高频报错。写索引前想清楚：这个字符串最长有多长？（第 3 章 range(len(s)) 就是为了不越界而生的。）

4.1.3 语法掌握：切片 [start:end:step]

切片用来取字符串的一段：s[start:end] 取从 start 到 end（不含 end）的字符。

代码案例 4.2：切片基础（✅ 正确）

python
s = "hello world"

print(s[0:5])    # 前 5 个
print(s[6:])     # 从第 6 个到末尾
print(s[:5])     # 从开头到第 5 个（等价 s[0:5]）
print(s[::2])    # 每 2 个取 1 个
print(s[::-1])   # 反转字符串！
print(s[-5:])    # 最后 5 个

运行结果：

hello
world
hello
hlowrd
dlrow olleh
world

讲解：

  • s[start:end]：含 start、不含 end（和 range 一样的规则）；
  • 省略 start 表示从开头，省略 end 表示到末尾；
  • s[::2] 的第三个参数是步长：每隔 2 个取 1 个；
  • s[::-1] 一步反转字符串——这是 Python 最优雅的语法之一，面试"反转字符串"的经典答案。

交叉验证：切片越界不报错！

❌ 新手以为会报错：

python
s = "hello"
print(s[0:100])

运行结果：

hello

讲解：切片超出范围不会报 IndexError，而是"能取多少取多少"——这是切片与索引访问的重大区别。索引严格（越界报错），切片宽容（自动截断）。

交叉验证：start 大于 end 得到什么？

python
print("abcde"[4:1])

运行结果：

（空字符串，什么也不输出）

讲解：s[4:1] 的 start（4）在 end（1）右边，取不到任何字符，返回空字符串。需要"从右往左取"时用负数步长："abcde"[4:1:-1] 得到 "edc"（自己运行验证）。

原理探秘：为什么切片这么宽容？

这是 Python 的设计哲学：切片用于"处理"，不用于"惩罚"。比如循环里 s[i:i+3] 处理最后不足 3 个字符的尾巴时，切片自动截断，程序就不用写一堆边界判断。宽容的输入、优雅的代码——但这种宽容也意味着：切片不会帮你发现"逻辑上取错了范围"的错误。

4.1.4 语法掌握：字符串不可变（复习 + 深化）

代码案例 4.3：尝试修改字符（✅ 观察）

python
s = "Python"
s[0] = "J"

实际报错：

TypeError: 'str' object does not support item assignment

讲解：字符串不可变，不能原地改某个字符。想得到"Jython"怎么办？用切片拼新字符串：

python
s = "Python"
s2 = "J" + s[1:]
print(s2)

运行结果：

Jython

讲解：s[1:] 是 "ython"，拼上 "J" 得到新字符串 "Jython"，原 s 仍然不变。所有"改字符串"的操作，本质都是"造一个新字符串"。

03. 4.2 字符串常用方法 ▼

方法（method）是"属于某个对象的函数"，写法是 字符串.方法名(参数)。这一节的方法都是返回新字符串，原字符串不变。

4.2.1 查找：find / rfind / index / count

代码案例 4.4：查找类方法（✅ 正确）

python
s = "hello world"

print(s.find("l"))      # 从左找第一个 l
print(s.rfind("l"))     # 从右找第一个 l
print(s.count("l"))     # l 出现次数
print(s.find("x"))      # 找不到返回 -1

运行结果：

2
9
3
-1

讲解：

  • find 返回第一次出现的索引；rfind 从右往左找；
  • count 统计出现次数；
  • find 找不到时返回 -1（不是报错）。

交叉验证：find vs index——找不到时的不同命运

❌ 易错：

python
print("hello".index("x"))

实际报错：

ValueError: substring not found

讲解：index 和 find 都能找索引，但找不到时 find 返回 -1，index 抛 ValueError。工程上：想"找不到就继续处理"用 find + 判断 -1；想"找不到就是异常"用 index。企业代码里 find 更常见，因为 -1 好处理。

4.2.2 判断：startswith / endswith / isalpha / isdigit / isspace

代码案例 4.5：判断类方法（✅ 正确）

python
filename = "report_2026.pdf"

print(filename.startswith("report"))
print(filename.endswith(".pdf"))
print("abc".isalpha())
print("中".isalpha())
print("123".isdigit())
print("3.14".isdigit())
print("   ".isspace())

运行结果：

True
True
True
True
True
False
True

讲解：

  • startswith / endswith：判断开头/结尾，处理文件名、URL、日志时超实用；
  • isalpha：是否全是字母——中文也算"字母"（Unicode 字母），所以 "中".isalpha() 是 True；
  • isdigit：是否全是数字字符——注意 "3.14" 含小数点，不是纯数字，返回 False；
  • isspace：是否全是空白。

交叉验证：用 isdigit 校验输入

✅ 正确（第 3 章的输入校验现在能写了）：

python
text = input("请输入一个整数：")
if text.isdigit():
    print(f"转换结果：{int(text) * 2}")
else:
    print("输入的不是纯数字，拒绝转换")

运行结果 1（输入 123）：

请输入一个整数：123
转换结果：246

运行结果 2（输入 12a）：

请输入一个整数：12a
输入的不是纯数字，拒绝转换

讲解：isdigit() 在转换前做"安检"，避免 int() 抛 ValueError 让程序崩溃。真实项目里"先校验、后转换"是铁律。注意：isdigit 对负数（"-5"）和负数符号返回 False，处理负数需要额外逻辑（挑战题）。

4.2.3 大小写：upper / lower / capitalize / title / swapcase

代码案例 4.6：大小写方法（✅ 正确）

python
print("hello".upper())
print("HELLO".lower())
print("hello".capitalize())
print("hello world".title())
print("Hello".swapcase())

运行结果：

HELLO
hello
Hello
Hello World
hELLO

讲解：upper 全大写、lower 全小写、capitalize 首字母大写其余小写、title 每个单词首字母大写、swapcase 大小写互换。真实场景：登录时把用户名统一 lower() 再比对，避免"Admin"和"admin"被视为两个用户。

4.2.4 拆分与合并：split / join

代码案例 4.7：split 与 join（✅ 正确）

python
names = "张三,李四,王五"
name_list = names.split(",")
print(name_list)

joined = "、".join(name_list)
print(joined)

运行结果：

['张三', '李四', '王五']
['张三', '李四', '王五']
张三、李四、王五

讲解：

  • split(分隔符)：字符串 → 列表（第 5 章学列表，先会用）；
  • join(列表)：列表 → 字符串，以调用它的字符串为连接符；
  • split 与 join 是互逆操作："a,b".split(",") 再 ",".join(...) 又回到 "a,b"。

原理探秘：为什么拼接推荐 join 而不是 += ？

字符串不可变，s += x 每次都会创建一个新字符串。在循环里拼 10000 次，就会创建 10000 个中间字符串——时间复杂度 O(n²)，程序肉眼可见地卡。

python
# 慢：循环里 += 拼接
s = ""
for ch in ["a", "b", "c"]:
    s += ch

# 快：先收集再 join
parts = ["a", "b", "c"]
s = "".join(parts)

小数据差别不大，大数据天壤之别。面试题"如何高效拼接大量字符串"，标准答案就是 join。

4.2.5 去除空白：strip / lstrip / rstrip

代码案例 4.8：strip 家族（✅ 正确）

python
text = "  你好，世界  "
print(repr(text.strip()))
print(repr(text.lstrip()))
print(repr(text.rstrip()))

运行结果：

'你好，世界'
'你好，世界  '
'  你好，世界'

讲解：

  • strip() 去掉两端空白；lstrip 去左边；rstrip 去右边；
  • repr() 能显示字符串的真实样子（包括空格），调试利器；
  • strip 也能去掉指定字符："###hello###".strip("#") 得到 "hello"。

交叉验证：忘记 strip 导致转换失败

❌ 易错：

python
num = input("请输入数字：")
print(int(num) * 2)

实际报错（用户输入" 123 "带空格）：

ValueError: invalid literal for int() with base 10: ' 123 '

✅ 修复：

python
num = int(input("请输入数字：").strip())
print(num * 2)

讲解：用户可能不小心敲了空格。输入先 strip 再转换，是处理用户输入的必备套路。真实场景：从 Excel、网页、表单读来的文本几乎都带隐藏空白。

4.2.6 替换：replace

代码案例 4.9：replace（✅ 正确）

python
msg = "hello world"
print(msg.replace("world", "Python"))
print(msg.replace("l", "L"))

运行结果：

hello Python
heLLo worLd

讲解：replace(旧, 新) 把所有出现的旧子串替换成新子串，返回新字符串。注意：原字符串不变（msg 还是 "hello world"），必须接收返回值。

交叉验证：replace 不改原字符串

❌ 易错：

python
msg = "hello world"
msg.replace("world", "Python")
print(msg)

运行结果：

hello world

讲解：忘了接收返回值，替换白做了。字符串方法大多返回新字符串，原字符串永远不变——这条"不可变"原则值得反复强调。

04. 4.3 格式化进阶：对齐、千分位、百分比 ▼

4.3.1 语法掌握：宽度与对齐

f-string 里可以指定最小宽度与对齐方式：:<宽度 左对齐、:>宽度 右对齐、:^宽度 居中。

代码案例 4.10：对齐报表（✅ 正确）

python
print(f"{'姓名':<6}|{'成绩':>6}")
print(f"{'张三':<6}|{88.5:>6.1f}")
print(f"{'李四':<6}|{95:>6.1f}")

运行结果：

姓名    |    成绩
张三    |  88.5
李四    |  95.0

讲解：

  • {'姓名':<6}：占 6 个字符宽度，左对齐（右边补空格）；
  • {88.5:>6.1f}：占 6 个宽度右对齐，保留 1 位小数；
  • 组合使用能做出对齐整齐的报表——真实场景：日志、终端工具、导出报告。

代码案例 4.11：千分位与百分比（✅ 正确）

python
total_sales = 1234567.89
rate = 0.856

print(f"总销售额：{total_sales:,.2f} 元")
print(f"达成率：{rate:.1%}")
print(f"人口：{1234567:,}")

运行结果：

总销售额：1,234,567.89 元
达成率：85.6%
达成率：85.6%

讲解：

  • :,.2f：千分位逗号 + 两位小数——金额报表标配；
  • :.1%：小数转百分比（自动 ×100 加 %），保留 1 位；
  • 第 2 章的 :.2f 是基础，本章的 , 和 % 是进阶，面试和实际报表都爱考。

4.3.2 综合运用：成绩单报表

代码案例 4.12：综合报表（✅ 正确）

python
students = [("张三", 88.5), ("李四", 95), ("王五", 76.25)]

print(f"{'姓名':<6}{'成绩':>8}")
print("-" * 14)
for name, score in students:
    print(f"{name:<6}{score:>8.1f}")

运行结果：

姓名          成绩
--------------
张三        88.5
李四        95.0
王五        76.2

讲解：students 是元组列表（第 5 章详解），for name, score in students 是"拆包遍历"。先把格式学好，数据结构的威力后面会放大。注意：数据、格式、输出分离，是工程化的雏形。

05. 4.4 编码基础：为什么会有乱码 ▼

4.4.1 概念认知：字符是怎么变成 0 和 1 的

计算机只存 0 和 1，所以每个字符都要有一套"字符 → 数字"的映射表，这叫编码。

代码案例 4.13：ord 与 chr（✅ 正确）

python
print(ord("A"))
print(chr(65))
print(ord("中"))
print(len("你好"))

运行结果：

65
A
20013
2

讲解：

  • ord(字符) 返回字符的编号；chr(编号) 反向得到字符；
  • "A" 的编号是 65（ASCII 标准）；
  • "中" 的编号是 20013（Unicode 标准）；
  • len("你好") 是 2——Python 3 按"字符"计数，不按"字节"。

原理探秘：ASCII、Unicode、UTF-8 三兄弟

  1. ASCII（1960s）：最早的标准，只有 128 个字符（英文字母、数字、符号、控制符），1 字节存储。中文？没有；
  2. Unicode：给全人类所有字符一个唯一编号（码点）。"中"的码点是 U+4E2D = 20013。但码点只是"编号"，不解决"怎么存"；
  3. UTF-8：Unicode 的一种存储方案：英文字符 1 字节（兼容 ASCII），中文 3 字节，按需变长，兼顾空间与兼容。

乱码的本质：同一个字节序列，用错误的编码去解读。比如把 UTF-8 的"中文"字节按 GBK 读，或者把 GBK 的字节按 UTF-8 读，就会得到一堆"锟斤拷"式的乱码。

就业提示：读文件、爬网页、接 API 时，遇到乱码先问"它是什么编码、我用什么编码读的"。Python 3 默认 UTF-8，第 9 章读写文件时会再次碰到这个主题。

06. 4.5 正则表达式入门（了解级） ▼

4.5.1 概念认知：用"模式"匹配文本

当你要在一段文本里查找"所有电话号码""所有数字""邮箱格式"时，字符串方法就力不从心了。正则表达式（Regular Expression） 用一套特殊语法描述"模式"，然后让 Python 去匹配。

本节约 10 分钟，目标是"认识 + 会抄着用"，详细语法在第 13 章（re 模块）系统讲解。import re 的模块机制第 8 章正式学。

代码案例 4.14：正则初体验（✅ 正确）

python
import re

text = "2026年8月6日，成交1234笔，退款56笔"

numbers = re.findall(r"\d+", text)
print(numbers)

if re.search(r"退款", text):
    print("文本中提到了退款")

运行结果：

['2026', '8', '6', '1234', '56']
文本中提到了退款

讲解：

  • \d+ 表示"一个或多个数字"；r"\d+" 前面的 r 表示原始字符串（反斜杠不转义）；
  • re.findall(模式, 文本) 找出所有匹配；
  • re.search(模式, 文本) 判断是否"存在匹配"；
  • 了解即可：能读懂"从文本里提取数字"这类代码，知道正则解决什么问题，第 13 章再系统学。

07. 4.6 本章 Debug 四件套 ▼

问题 1：索引越界

问题代码：

python
name = "Bob"
print(name[3])

预期输出：

B

实际输出：

IndexError: string index out of range

提示："Bob" 有 3 个字符，索引范围是多少？想取最后一个字符该用什么索引？

讲解：合法索引 0~2，name[3] 越界。想取最后一个字符，用 name[-1]，不要数长度。真实场景：处理用户输入、文件行时，长度不可控，越界风险最高。

问题 2：find 返回 -1 没检查

问题代码：

python
email = "zhangsan@example.com"
pos = email.find("@")
print(email[pos + 1:])

预期输出：

example.com

实际输出（如果输入 "zhangsan" 没有 @）：

（空输出，且 pos = -1，切片 email[0:] 输出了整个字符串——逻辑错误）

提示：find 找不到返回什么？你对 -1 做判断了吗？

讲解：find 找不到返回 -1。如果直接 pos + 1 用，切片会从错误位置开始。使用 find 后必须检查 if pos != -1。真实场景：解析用户输入、配置文件时，"找不到分隔符"是常见输入错误。

问题 3：split 后索引越界

问题代码：

python
line = "hello"
parts = line.split(",")
print(parts[1])

预期输出：

world

实际输出：

IndexError: list index out of range

提示："hello" 里没有逗号，split 后的列表有几个元素？

讲解："hello".split(",") 得到 ["hello"]，只有 1 个元素，parts[1] 越界。先判断 len(parts) 再取下标，或者用"至少一个分隔符"的输入。真实场景：解析 CSV 行时，字段数不足是高频崩溃点。

问题 4：忘了 strip 导致转换失败

问题代码：

python
price = input("请输入价格：")
print(int(price))

预期输出（输入" 99 "带空格）：

99

实际输出：

ValueError: invalid literal for int() with base 10: ' 99 '

提示：看看输入里有没有看不见的空格？哪个方法能去掉它？

讲解：用户输入常带空格，int(" 99 ") 报错。input().strip() 再转换是标准姿势。真实场景：从表单、Excel、网页读来的文本几乎都带隐藏空白。

09. 4.8 本章小结与知识树 ▼

知识树：

字符串深入
├── 索引：从 0 开始；负数从右数（s[-1] 最后一个）；越界报 IndexError
├── 切片 [start:end:step]
│   ├── 含头不含尾；省略 start/end 即开头/末尾
│   ├── 步长：s[::2] 隔一个；s[::-1] 反转
│   └── 越界不报错（宽容截断）；start>end 得空串
├── 方法（都不改原字符串！）
│   ├── 查找：find（找不到 -1）/ rfind / index（找不到报错）/ count
│   ├── 判断：startswith / endswith / isalpha / isdigit / isspace
│   ├── 大小写：upper / lower / capitalize / title / swapcase
│   ├── 拆分合并：split（串→表）/ join（表→串），互逆
│   ├── 去空白：strip / lstrip / rstrip（转换前必用）
│   └── 替换：replace（记得接收返回值）
├── 格式化：:< 左对齐 / :> 右对齐 / :^ 居中 / :, 千分位 / :.1% 百分比
├── 编码：ASCII（1 字节）→ Unicode（编号）→ UTF-8（存储）；乱码=编码错配
└── 正则（了解）：\d+ 数字、re.findall / re.search、r 原始字符串

必须记住的 5 件事：

  1. 索引越界报错，切片越界不报错——严格 vs 宽容；
  2. find 找不到返回 -1，index 找不到抛异常；用 find 必须检查 -1；
  3. 所有字符串方法都返回新字符串，原字符串不变；
  4. 用户输入先 strip() 再转换；
  5. split 与 join 互逆，大量拼接用 join 不用 +=。
