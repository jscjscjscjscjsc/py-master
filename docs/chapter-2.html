01. 什么是变量？ ▼

变量的概念

变量是一个存储数据的容器。想象你有一个贴了标签的盒子，标签叫 name，盒子里装着 "Alice"，以后提到 name 就知道里面是什么。

name = "Alice"   # 把 "Alice" 放进贴了 name 标签的盒子
age = 25          # 把 25 放进贴了 age 标签的盒子
print(name)       # 输出盒子里的内容 → Alice

Python 变量 vs 其他语言

Python 不需要声明变量类型：

# Java/C++ 风格（Python 不需要这样做）
int age = 25;      # 声明类型
String name = "Tom";  # 声明类型

# Python 风格（直接赋值，自动推断类型）
age = 25           # Python 自动知道这是整数
name = "Tom"       # Python 自动知道这是字符串

变量命名规则（必记！）

  • 只能包含字母、数字和下划线（_）
  • 不能以数字开头
  • 区分大小写（name、Name、NAME 是三个不同变量）
  • 不能使用 Python 关键字（如 if、for、while、class、def 等）
# ✅ 合法的变量名
name = "Alice"
age = 25
user_name = "bob"
_count = 100         # 下划线开头也合法（常用于私有变量）
名字 = "小明"         # Python 3 支持中文变量名（但不推荐）

# ❌ 不合法的变量名
2name = "error"      # 不能以数字开头
my-name = "error"    # 不能使用连字符
if = 10              # 不能使用关键字

命名规范（PEP 8 官方推荐）

  • 变量和函数：小写字母 + 下划线 my_variable、calculate_score()
  • 类名：大驼峰 StudentRecord、DataAnalyzer
  • 常量：全大写 + 下划线 MAX_SIZE = 100、PI = 3.14
  • 见名知意：student_name 远好于 sn 或 s

变量重新赋值与类型变化

x = 10        # x 是整数
print(x)      # 10
x = "hello"   # x 现在是字符串了（Python 允许这样做）
print(x)      # hello
x = [1,2,3]   # x 又变成列表了
print(x)      # [1, 2, 3]

这叫动态类型——同一个变量在不同时刻可以指向不同类型的数据。

02. 数字类型 ▼

整数（int）

没有小数点的数字。Python 3 中整数可以任意大（不受 32 位或 64 位限制），只要内存够大：

age = 25
year = 2024
population = 8_000_000_000  # 下划线作为千分位分隔符，更易读
big = 123456789012345678901234567890  # Python 自动处理大整数

浮点数（float）

带小数点的数字。计算机用 IEEE 754 标准存储浮点数，存在精度问题：

pi = 3.1415926
height = 1.75
speed_of_light = 3e8  # 科学计数法：3 × 10⁸

# ⚠️ 浮点数精度问题
print(0.1 + 0.2)       # 0.30000000000000004（不是精确的 0.3！）
print(0.1 + 0.2 == 0.3)  # False！

# 解决方案：用 round() 或 decimal 模块
print(round(0.1 + 0.2, 1))  # 0.3 ✓

复数（complex）

Python 原生支持复数，数学和工程计算很方便：

c = 3 + 4j
print(c.real)    # 3.0（实部）
print(c.imag)    # 4.0（虚部）
print(abs(c))    # 5.0（模长 = sqrt(3²+4²)）
print(c * c)     # (-7+24j)

类型判断与转换

# 判断类型
print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(isinstance(42, int))  # True

# 类型转换
int("123")      # 123（字符串→整数）
int(3.99)       # 3（浮点→整数，直接截断不四舍五入）
float("3.14")   # 3.14
float(10)       # 10.0
str(100)        # "100"（数字→字符串）
bool(0)         # False
bool("hello")   # True（非空字符串为 True）

常用数值运算

print(abs(-5))       # 5（绝对值）
print(pow(2, 10))    # 1024（2的10次方，等价于 2**10）
print(divmod(17, 5)) # (3, 2)（商和余数）
print(max(1,5,3))    # 5（取最大值）
print(min(1,5,3))    # 1（取最小值）
print(round(3.14159, 2))  # 3.14（四舍五入保留2位）

03. 字符串类型（str） ▼

创建字符串的四种方式

s1 = 'Hello'              # 单引号
s2 = "Python"             # 双引号（效果相同）
s3 = '''第一行
第二行
第三行'''                  # 三单引号：保留换行
s4 = """也是多行
字符串"""                  # 三双引号：常用于文档字符串(docstring)

引号的选择：单引号和双引号在 Python 中完全等价。当字符串内含引号时交替使用："I'm fine" 或 '他说"你好"'。

转义字符

转义含义转义含义
\n换行\t制表符(Tab)
\\反斜杠本身\'单引号
\"双引号\r回车
print("第一行\n第二行")   # 换行输出
print("他说：\"你好\"")    # 在字符串中包含引号
print("路径：C:\\\Users\\Admin")  # 路径中的反斜杠

原始字符串（raw string）

# 原始字符串中 \ 就是普通的 \，不用转义
path = r"C:\Users\Admin\Documents"  # r 前缀
print(path)  # C:\Users\Admin\Documents

字符串基本操作

name = "Alice"
# 拼接
greeting = "Hello, " + name  # "Hello, Alice"
# 重复
print("Hi" * 3)       # "HiHiHi"
# 长度
print(len(name))      # 5
# 索引（从 0 开始）
print(name[0])        # "A"
print(name[-1])       # "e"（倒数第一个）
print(name[-2])       # "c"（倒数第二个）
# 成员检查
print("li" in name)   # True

f-string 格式化（Python 3.6+，推荐！）

name = "Bob"
age = 20
score = 92.567
# 基本用法
print(f"我叫{name}，今年{age}岁")
# 表达式直接嵌入
print(f"明年{age + 1}岁")
# 格式控制
print(f"分数：{score:.1f}")     # 92.6（保留1位小数）
print(f"{name:>10}")            # "      Bob"（右对齐，占10格）
print(f"{name:*^10}")           # "***Bob****"（居中对齐，*填充）
# 大数字千分位
num = 1234567890
print(f"{num:,}")               # 1,234,567,890

字符串不可变性

s = "Hello"
# s[0] = "h"   # ❌ 报错！字符串不能修改单个字符
s = "h" + s[1:]  # ✅ 正确做法：创建新字符串
print(s)         # "hello"

04. 布尔类型与 None ▼

布尔值（bool）

只有两个值：True 和 False。注意首字母必须大写！

is_student = True
is_raining = False
print(10 > 5)     # True
print(3 == 5)     # False

哪些值被视为 False？

在条件判断中，以下值等同于 False（称为 falsy 值）：

类型Falsy 值
数字0, 0.0, 0j
字符串""（空字符串）
容器[]（空列表）、{}（空字典）、()（空元组）、set()（空集合）
NoneNone
布尔False

除此以外的所有值都视为 True（truthy）。

# 利用 falsy/truthy 写的简洁条件
name = ""          # 空字符串是 falsy
if not name:       # 等价于 if name == ""
    print("名字不能为空")

items = []         # 空列表是 falsy
if items:          # 等价于 if len(items) > 0
    print("有内容")
else:
    print("列表为空")

None 类型

None 代表「没有值」或「空」，是 Python 的空对象。常用于：

  • 函数的默认返回值（无 return 语句时返回 None）
  • 表示变量尚未赋值
  • 初始化占位
result = None  # 先占个位，后面再赋值
if result is None:
    print("还没有结果")
# 判断 None 应该用 is，而不是 ==
# None 是单例，is 更快且不会被自定义 __eq__ 干扰

布尔运算

# and: 两者都 True 才返回 True
print(True and True)   # True
print(True and False)  # False

# or: 一个为 True 就返回 True
print(True or False)   # True
print(False or False)  # False

# not: 取反
print(not True)   # False
print(not False)  # True
