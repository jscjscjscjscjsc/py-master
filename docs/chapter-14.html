02. 14.1 综合案例一：命令行学生信息管理系统 ▼

14.1.1 需求分析

做一个菜单驱动的学生信息管理系统：

1. 查看所有学生
2. 添加学生
3. 删除学生
4. 按姓名查找
5. 退出

要求：数据用字典存（姓名/年龄/成绩），程序重启后数据还在（存 JSON 文件）。

知识点：函数、字典列表、循环、异常、JSON 文件读写——第 2-9 章全串起来了。

14.1.2 分步设计

拆成 5 个函数，每个单一职责（第 7 章模块化思想）：

函数职责
load_students()从 JSON 读数据（文件不存在/损坏时返回空列表）
save_students(students)把数据写回 JSON
list_students(students)显示所有学生
add_student(students)输入信息并加入列表
delete_student(students)按姓名删除
find_student(students)按姓名查找
main()菜单循环 + 调用上述函数

14.1.3 完整代码（案例 14.1，✅ 正确）

python
import json

STUDENTS_FILE = "students.json"

def load_students():
    """从文件读取学生列表；文件不存在或损坏时返回空列表"""
    try:
        with open(STUDENTS_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    except (FileNotFoundError, json.JSONDecodeError):
        return []

def save_students(students):
    """保存学生列表到文件"""
    with open(STUDENTS_FILE, "w", encoding="utf-8") as f:
        json.dump(students, f, ensure_ascii=False, indent=2)

def list_students(students):
    """显示所有学生"""
    if not students:
        print("暂无学生")
        return
    for i, s in enumerate(students, 1):
        print(f"{i}. {s['name']}，{s['age']}岁，成绩 {s['score']}")

def add_student(students):
    """添加学生"""
    name = input("姓名：")
    age = int(input("年龄："))
    score = int(input("成绩："))
    students.append({"name": name, "age": age, "score": score})
    print("添加成功")

def delete_student(students):
    """按姓名删除"""
    name = input("要删除的学生姓名：")
    for s in students:
        if s["name"] == name:
            students.remove(s)
            print(f"已删除 {name}")
            return
    print("未找到该学生")

def find_student(students):
    """按姓名查找"""
    name = input("要查找的姓名：")
    for s in students:
        if s["name"] == name:
            print(f"{s['name']}，{s['age']}岁，成绩 {s['score']}")
            return
    print("未找到")

def main():
    students = load_students()
    while True:
        print("=" * 30)
        print("学生信息管理系统")
        print("1. 查看所有学生")
        print("2. 添加学生")
        print("3. 删除学生")
        print("4. 按姓名查找")
        print("5. 退出")
        print("=" * 30)

        choice = input("请选择：")
        if choice == "1":
            list_students(students)
        elif choice == "2":
            add_student(students)
            save_students(students)
        elif choice == "3":
            delete_student(students)
            save_students(students)
        elif choice == "4":
            find_student(students)
        elif choice == "5":
            save_students(students)
            print("再见")
            break
        else:
            print("无效选择，请重新输入")

if __name__ == "__main__":
    main()

03. 14.2 综合案例二：数据清洗小工具 ▼

14.2.1 需求分析

一份原始 CSV（raw.csv）数据很脏：有负数成绩、有非数字、有超范围值。写一个工具：读取 → 清洗（跳过脏数据并提示）→ 写出干净文件。

name,score
张三,88
李四,-5        ← 负数，跳过
王五,abc       ← 非数字，跳过
赵六,95
钱七,120       ← 超范围，跳过

14.2.2 完整代码（案例 14.2，✅ 正确）

python
import csv

def read_raw(path):
    """读取原始 CSV，返回所有行（含表头）"""
    rows = []
    with open(path, "r", encoding="utf-8") as f:
        for row in csv.reader(f):
            rows.append(row)
    return rows

def clean_rows(rows):
    """清洗：跳过负数、非数字、超范围成绩"""
    cleaned = [rows[0]]                 # 保留表头
    for row in rows[1:]:
        try:
            name = row[0].strip()
            score = int(row[1])
            if score < 0 or score > 100:
                print(f"跳过异常成绩：{name} {score}")
                continue
            cleaned.append([name, score])
        except (ValueError, IndexError):
            print(f"跳过脏数据：{row}")
    return cleaned

def save_clean(rows, path):
    """写出清洗后的 CSV"""
    with open(path, "w", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        writer.writerows(rows)

raw = read_raw("raw.csv")
cleaned = clean_rows(raw)
save_clean(cleaned, "clean.csv")
print(f"清洗完成：{len(raw) - 1} 行 → {len(cleaned) - 1} 行")

运行结果：

跳过异常成绩：李四 -5
跳过脏数据：['王五', 'abc']
跳过异常成绩：钱七 120
清洗完成：5 行 → 2 行

讲解：

  • 脏数据三兄弟：负数（业务异常）、非数字（类型异常）、超范围（业务异常）——分别用 if 校验和 try/except 兜底；
  • row[0].strip()：去掉名字两边的空格（第 4 章）；
  • int(row[1]) 放 try 里：转换失败就是脏数据（第 9 章异常处理实战）；
  • 结论输出：清洗前后行数对比，让使用者知道发生了什么。

真实场景：从 Excel/表单/爬虫拿来的数据几乎都脏。你以后在 pandas（第 26 章）里学的"数据清洗"，本质就是这套"读 → 校验 → 转换 → 写"的流程。

04. 14.3 综合案例三：猜词游戏 ▼

14.3.1 需求分析

从单词表随机选一个词，玩家猜字母：

  • 猜中显示进度（pyt___），猜错扣机会；
  • 机会用完失败，猜完单词胜利；
  • 重复猜过的字母给提示，不扣机会。

知识点：random、集合（去重猜过的字母）、字符串（显示进度）、while 循环。

14.3.2 完整代码（案例 14.3，✅ 正确）

python
import random

WORDS = ["python", "vibe", "coding", "program", "computer", "keyboard"]

def choose_word():
    """随机选一个单词"""
    return random.choice(WORDS)

def show_progress(word, guessed):
    """显示当前猜测进度，如 p y t _ _ _"""
    return " ".join(ch if ch in guessed else "_" for ch in word)

def play():
    word = choose_word()
    guessed = set()
    chances = 6

    while chances > 0:
        progress = show_progress(word, guessed)
        print(f"当前：{progress}，剩余机会：{chances}")

        if "_" not in progress:
            print("恭喜，你猜对了！")
            return

        guess = input("猜一个字母：").lower().strip()
        if guess in guessed:
            print("这个字母猜过了")
            continue

        guessed.add(guess)
        if guess in word:
            print("猜对了！")
        else:
            chances -= 1
            print(f"猜错了，还差 {chances} 次机会")

    print(f"游戏结束，答案是：{word}")

if __name__ == "__main__":
    play()

运行结果（示例）：

当前：_ _ _ _ _ _，剩余机会：6
猜一个字母：p
猜对了！
当前：p _ _ _ _ _，剩余机会：6
猜一个字母：x
猜错了，还差 5 次机会
...

讲解：

  • 集合 guessed：天然去重，重复猜同一字母时 if guess in guessed 拦截；
  • 进度显示：生成器表达式（第 12 章）" ".join(...) 把已猜中的字母显示出来；
  • lower().strip()：统一小写、去空格，防用户输入差异（第 4 章）；
  • return vs 循环结束：猜中 return 提前结束；机会耗尽自然退出 while 并打印答案。

扩展思路（课后挑战）：如果玩家一次猜整个单词（guess == word 直接胜利），代码怎么改？把机会从 6 次改成按单词长度计算呢？

import json

with open("students.json", "r", encoding="utf-8") as f:
    students = json.load(f)

def calc_avg(s):
    return sum(s["scores"]) / len(s["scores"])

ranked = sorted(students, key=calc_avg, reverse=True)

for s in ranked:
    print(f"{s['name']}：{calc_avg(s):.1f}")

运行结果（students.json 含两个学生）：

参考答案：

python
users = {"zhangsan": "123456"}

for attempt in range(1, 4):
    username = input("用户名：")
    password = input("密码：")

    if users.get(username) == password:
        print("欢迎登录！")
        break
    else:
        left = 3 - attempt
        if left > 0:
            print(f"用户名或密码错误，还剩 {left} 次机会")
        else:
            print("账户已锁定")

用户名：zhangsan

🔍 解析

users.get(username) == password 用 get 防止 KeyError（第 6 章）；for range(1, 4) 控制 3 次；left = 3 - attempt 计算剩余次数；成功 break 退出。

第 7 题：文本统计器：读取一个文本文件，统计：总行数、总单词数、出现次数最多的单词及其次数（用字典 + 循环，忽略大小写和标点）。对 poem.txt 运行并输出结果。

📝 参考答案

参考答案：

python
import re

with open("poem.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()

word_count = {}
total_words = 0

for line in lines:
    words = re.findall(r"[a-zA-Z]+", line.lower())
    total_words += len(words)
    for word in words:
        if word in word_count:
            word_count[word] += 1
        else:
            word_count[word] = 1

best_word = ""
best_count = 0
for word, count in word_count.items():
    if count > best_count:
        best_count = count
        best_word = word

print(f"总行数：{len(lines)}")
print(f"总单词数：{total_words}")
print(f"出现最多的单词：{best_word}，{best_count} 次")

运行结果（示例文本）：

总行数：4
总单词数：25
出现最多的单词：the，5 次
🔍 解析
  • re.findall(r"[a-zA-Z]+", line.lower())：只提取英文单词、统一小写、自动去标点（第 13 章正则）；
  • 计数器模式（第 6 章）：in 判断 → 加 1 或初始化；
  • 打擂台找最大值（第 3 章）；
  • 知识点串烧：文件（第 9 章）、正则（第 13 章）、字典（第 6 章）、循环（第 3 章）。
