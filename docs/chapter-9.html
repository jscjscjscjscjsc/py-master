文件打开模式

模式说明文件不存在

'a'追加（末尾添加）创建新文件

02. 文件写入与 with 语句 ▼

读取文件的多种方式

# 1. read(): 读取整个文件（适合小文件）
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)

# 2. read(n): 读取 n 个字符
with open("test.txt", "r", encoding="utf-8") as f:
    chunk = f.read(100)  # 读前100个字符
    while chunk:
        process(chunk)
        chunk = f.read(100)

# 3. readline(): 逐行读取
with open("test.txt", "r", encoding="utf-8") as f:
    line = f.readline()
    while line:
        print(line.strip())
        line = f.readline()

# 4. readlines(): 一次性读入所有行到列表
with open("test.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()  # ['第一行\n','第二行\n',...]

# 5. for line in f: 逐行迭代（最推荐！内存友好）
with open("test.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

写入文件

# write(): 写入字符串
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello, World!\n")
    f.write("第二行\n")

# writelines(): 写入字符串列表
lines = ["第一行\n", "第二行\n", "第三行\n"]
with open("output.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)

# 注意：writelines 不会自动加换行符！
# 如果不加 \n，所有内容会挤在一行

追加模式（a）

# 追加模式：不清空已有内容，在末尾添加
with open("log.txt", "a", encoding="utf-8") as f:
    from datetime import datetime
    f.write(f"[{datetime.now()}] 程序启动\n")

03. 异常处理基础 ▼

with 语句（上下文管理器）

with 语句确保文件在使用完毕后自动关闭，即使发生异常：

# ✅ 推荐：使用 with
with open("file.txt", "r", encoding="utf-8") as f:
    content = f.read()
    # 发生异常也不怕！文件会被正确关闭
# 离开 with 块，文件自动关闭

# ❌ 不推荐：手动管理
f = open("file.txt", "r")
try:
    content = f.read()
finally:
    f.close()  # 必须写在 finally 里才能保证异常时也关闭

with 同时打开多个文件

# Python 3.1+ 可以一行写多个 with
with open("input.txt","r") as fin, open("output.txt","w") as fout:
    for line in fin:
        fout.write(line.upper())  # 转换为大写后写出

文件对象常用属性与方法

with open("test.txt", "r", encoding="utf-8") as f:
    print(f.name)       # 文件名
    print(f.mode)       # 打开模式 'r'
    print(f.encoding)   # 编码 'utf-8'
    print(f.closed)     # 是否已关闭 → False
    # f.seek(0)         # 移动文件指针到开头
    # f.tell()          # 获取当前指针位置

print(f.closed)         # True（with 离开后已自动关闭）

import csv

04. 异常处理进阶 ▼

常见异常类型

异常类型触发条件示例
ValueError值不合法int("abc")
TypeError类型不匹配"a" + 1
IndexError列表索引越界[1,2][5]
KeyError字典键不存在{}[key]
FileNotFoundError文件不存在open("no")
ZeroDivisionError除以零1/0
NameError变量未定义print(x)
AttributeError属性不存在"x".fly()
ImportError模块导入失败mod 不存在

异常处理完整结构

try:
    # 可能发生异常的代码
    num = int(input("输入数字: "))
    result = 100 / num
    print(f"100 / {num} = {result}")

except ValueError:
    # 捕获值错误
    print("请输入有效的整数！")

except ZeroDivisionError:
    # 捕获除零错误
    print("除数不能为零！")

except (TypeError, KeyError) as e:
    # 同时捕获多个异常类型
    print(f"捕获到异常: {type(e).__name__}: {e}")

else:
    # 没有异常时执行（可选）
    print("计算成功！")

finally:
    # 无论是否有异常都会执行（可选，用于清理）
    print("程序结束。")

获取异常详情

import traceback

try:
    x = 1 / 0
except ZeroDivisionError as e:
    print(f"异常类型: {type(e).__name__}")  # ZeroDivisionError
    print(f"异常消息: {e}")                 # division by zero
    # traceback.print_exc()                 # 打印完整回溯

主动抛出异常

def check_age(age):
    if age <= 0:
        raise ValueError(f"年龄必须为正数，现在是 {age}")
    if age > 150:
        raise ValueError(f"年龄不可能超过150岁，现在是 {age}")
    return age

# 使用
try:
    check_age(-5)
except ValueError as e:
    print(e)  # 年龄必须为正数，现在是 -5

自定义异常

class ScoreError(Exception):
    """自定义分数异常"""
    pass

def validate_score(score):
    if not 0 <= score <= 100:
        raise ScoreError(f"分数必须在 0-100 之间，当前值: {score}")
    return score

# 使用
try:
    validate_score(150)
except ScoreError as e:
    print(f"验证失败: {e}")

最佳实践

  • 只捕获预期可能发生的异常，不要无差别 except Exception
  • 异常处理不要隐藏错误（不要 pass 掉异常不处理）
  • 不用异常控制正常流程（异常是"异常"情况，不是正常分支）
  • 在 finally 中释放资源（或用 with 自动管理）
  • 抛出异常优于返回错误码（Python 风格）
