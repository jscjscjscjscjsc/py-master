一、修好了"字看不清"的问题

上一版加了氛围层之后，有两处文字被压得发虚，这次都处理了。

修行阁的标题原来是浅色细笔画压在暖色绢底上，眼睛抓不住轮廓。 现在改成泥金做法 —— 墨为骨、金为肉：先用深墨把笔画轮廓钉住， 再让金色只从边缘和转角透出来，最后叠一层斜向高光，模拟金箔的反光。 神功名录、装备名、法相名号、段标题都上了金，并按状态分三档明度： 当前在修的功法最亮，已得的次之，还没解锁的是暗哑的青铜金 —— 用明暗区分状态，而不是把没解锁的全灰掉（新账号一进来 30 张卡全是灰的， 整页就像糊了一层，反而更看不清）。

浅色主题下的教案代码区是上一版留下的真问题：浅色主题只覆盖了正文和卡片， 代码块、行内代码、表格、引用全都没有对应配色，深色底配深色字，基本读不出来。 现在浅色主题下代码区改成"纸上印字"（浅灰纸面 + 深墨字）， 而不是在白页面上嵌一块深色小窗。顺带把页面底色让给了氛围层 —— 原来各页面自己铺了一层不透明的深色底，把星云整层盖住了， "氛围做了却看不见"就是这个原因。

二、教案排版重做

原来的教案正文和普通博客没区别，信息层级压不住背景。这次按讲义的规矩重排：

  • 小标题左侧加一道竖笔（墨骨），一眼能扫出结构
  • 列表换成方标 / 序号块，读起来是"要点"而不是"段落"
  • 代码块有顶栏（三颗小圆点 + 语言标签 + 复制按钮），和正文明显分开；
  • 表格加了圆角边框、表头底色、隔行浅底、悬停高亮
  • 引用块用一道竖线加引号，教材里"常听到一句话"这类内容有了形状
  • 正文行宽限制在 74 字符，中文长段落不再一眼望不到头
  • 顺手修好一个一直存在的 bug：代码块的复制按钮点了没反应 ——

三、氛围层在浅色主题下换成另一种材质

以前浅色主题是把深色星云调淡，结果白卡片浮在一层灰绿的雾上。 现在浅色主题走纸面材质：米白宣纸底 + 极淡的暖灰晕 + 少量浮尘， 和深色模式是两种材质，不是同一张图调亮度。切换主题时会实时换过来。

一、打开就能看到一部开场短片

以前双击启动脚本，浏览器打开后直接是仪表盘；现在会先放一部约一分钟的 开场引导 CG，讲清楚三件事：Python 从哪来、Python 之禅是什么、 以及为什么在 AI 竞赛的当下，Python 值得你花时间。

五幕结构：

幕主题画面
00溯源1989 年圣诞，阿姆斯特丹；Python 标志由粒子聚合成形
01禅Python 之禅 19 条信条，像碑林一样向远处铺开、逐条点亮
02龟叔Guido van Rossum 的全息点云像，扫描环上下扫过
03大竞赛语言排行榜的 3D 天际线 + 五张可点开的数据卡片
04启程巨型 PYMASTER 字标与向心星流，转入平台

可以跳过：右上角「跳过片头」、或者直接按 Esc。 只看一次：看过之后再打开就直接进平台，不会每次都放。 想看第二遍：登录页左下角、以及登录后点右上角头像，都有「重看开场 CG」。

二、这场 CG 是能上手玩的，不是一段视频

它不是预渲染的视频文件，是浏览器里实时跑的 3D 场景 —— 所以你可以动手：

  • 滚轮 / 拖动 / 方向键推进剧情，松手有惯性；也可以放着不管，它会像电影一样自动往下走，你一动它就交还控制权
  • 右侧竖直章节导航：滚动时高亮自动跟随，鼠标压到节点上会有水波扩散，点一下直接飞到那一幕
  • 水流触感：鼠标划过的地方，背景星云会被涟漪顶开，画面里会留下水面波纹
  • 横向 3D 卡片：第三幕的五张卡片会跟着指针倾斜，点开时卡片向前伸出、其余卡片被推开，并伴随一圈冲击波
  • 环境音：程序实时合成的深海氛围垫音，点按、悬停、换幕各有一种水滴声（右上角可关）

技术说明：用本地自带的 three.js 实时渲染，不联网、无外部素材。 没有 WebGL 的老机器会自动降级成 2D 版，文字与交互照常，短片照样看得完。

三、登录页重新设计

原来的登录页是一张深色卡片加两个 emoji 图标，模板味比较重。现在换成：

  • 左侧品牌区：巨型 PYMASTER 字标、轮播的 Python 之禅、平台数据一览（39 章 / 400 知识点 / 256 题 / 30 级修为）
  • 右侧认证卡：登录与注册改为滑动分段切换，输入框有聚焦光晕，密码可以点小眼睛查看明文
  • 本机账号直接摆成一排头像，点一下自动填好用户名，不用手打
  • 整页背景与开场 CG 同一套视觉语言（深海底色 + 有机孢子 + 星野视差），点哪儿哪儿起涟漪

登录、注册、本机账号切换、头像上传这些功能一个都没变，只是换了一身皮。

四、修为长成了一个真正能玩下去的系统：修行阁

以前「修为等级」就是一条进度条：涨分、升级、仅此而已。现在它变成了一间 修行阁（导航栏或仪表盘上的「修行阁」都能进），十境三十级，每一境都有：

  • 一张属于你的神识画像：不是贴图，是按你的账号 + 当前境界实时生成的。
  • 一门计算机神功：每升一级得一门，名字全是计算机术语，而不是玄幻词——
  • 一批靠实力解锁的装备：18 件，每件都写着解锁方式与当前进度。
  • 境界试炼：每个大境界三条目标（通关量 / 满星质量 / 连续天数 / 实战组卷），
  • 修行地图：十境一条路，一眼看到自己在哪、下一境要多少修为、哪几境试炼已过。
  • 攻略：不是写死的教程，是按你的现状算的——还差多少修为、做哪一道题最快

一句话：刷题 → 修为 → 境界 → 神功与画像 → 较难题解锁装备 → 试炼突破奖励 → 下一境， 闭环收口了。等级条也换了新面貌：不再是彩色圆点，而是该境界的矢量法印。

五、星辰教练身后那片星空，重画了一遍

打开「星辰教练」就能看到：原来的背景是黑底上撒了点星星，现在是一整片星河—— 有星云、有银河带、有暗尘带，还有脚下慢慢飘的云海。而且它是跟着你的境界换的： 金丹期是金芯的天，元婴期是紫色的天，化神期是青色的天，金仙是玉色的天。 同一页在不同境界看，是不一样的星空。

具体多了什么：

  • 星云：用算法现场生成（域扭曲噪声），不是贴图，所以每一片云都是真的在缓慢流动。
  • 银河与暗尘带：一条斜贯画面的银河，中间还有把背景星光挡住的暗尘——有了这道暗，
  • 几千颗星：按真实星等分布——绝大多数又小又暗，极少数又大又亮还带衍射星芒。
  • 云海：脚边三条不同速度的雾带，横着缓缓淌。它同时干一件事：把法相托起来，
  • 指针视差：鼠标一动，近处的星、远处的星、法相各按不同幅度偏一点。

金丹也重做了

金丹期起，教练丹田那颗金丹以前是"两个圆叠起来"——放大看就是个灯泡。现在由外到内 七层：外层辉光、日冕、倾斜的吸积盘（前后两半分开画，所以是立体的）、 绕核旋进的能量丝（每条转速不同）、三段渐变的球体（高温心 + 焦外缘， 有体积）、球面上缓慢自转的丹纹、向外扩散的脉冲环与带拖尾的绕行小星。 辉光是故意溢出躯干的——这一条决定了它是"体内在烧"还是"胸口贴了个亮片"。

法相与文字重新排版

以前正文列停在正中间，法相的脑袋正好压在文案上，所以法相只能画得很淡。 现在把正文列左移收窄，右边一整条留给法相——左文右像，两者都不用再互相让。 空态还多了一束从头顶落下的光柱。

三档背景，默认给最满的那一版

右上角「✦ 星海 / ✦ 微光 / ◌ 纯净」三档照旧，你的选择会记住。 只是第一次进来默认给星海档（以前默认微光），先把最满的那一版给你看； 嫌吵就点两下切到微光或纯净，切过之后就一直是它。

性能说明：所有星云都是一次性算好的贴图，逐帧只做贴图合成； 星点全部走预渲染发光图，实测每帧绘制耗时约 0.5 毫秒。 老机器连续掉帧会自动降档；系统开了「减少动态效果」会直接停成一张静态星空。

一句话概括：PyMaster 从「Python 基础语法演示 Demo」升级为「从零基础到 AI 应用开发的完整学习平台」， 并为每一个知识点配上了一节 5 分钟的 AI 图文讲解。

二、三大核心升级

1. 课程内容：从语法打通到 AI 开发

新教材按五篇组织，学习路径连贯：

合计 39 章 / 400 个知识点 / 212 道练习（全部带答案与解析）。

2. 每个知识点配一节 5 分钟图文讲解

这是本次最大的体验升级。原来是"角色对白气泡 + 机器朗读"，信息密度低、没有画面。 现在每个知识点对应一节完整的短视频课：

  • 16 个镜头，每节实测 5 分 00 秒 – 5 分 20 秒
  • 每个镜头一张课件图，7 种版式对应不同教学环节：
  • 口播由 AI 老师讲述，配字幕要点，支持自动连播、倍速、逐句高亮、点击任意镜头跳转
  • 讲解稿严格基于教材原文生成，不引入教材里没有的 API 或结论

讲解不再是预设内容——平台可以现场生成：在章节页点「🎬 5 分钟图文讲解」， 如果这节还没做，界面会提示并支持一键现场生成，3–5 分钟出结果。

3. 配图改为程序化生成（不依赖任何外部生图服务）

配图不是"AI 画的"，而是用代码精确排版生成的。这个选择带来三个实际好处：

生成式 AI 画图程序化作图（现方案）
中文显示常出现乱码伪文字完全正确
风格一致性同一节课里画风会漂移完全统一，形象固定
生成速度每张约 8 秒，需联网每秒 8–14 张，纯本地
使用成本按张计费，有额度上限零成本，可无限量生产
代码/表格画不准精确排版，语法着色

对技术课件来说，"能把代码和术语写对"比"画得好看"重要得多。这也意味着 全量 6400 张配图可以在几分钟内本地重建，不需要任何第三方额度。

四、怎么使用

方式一：本地运行完整版（推荐，功能最全）

双击 启动 PyMaster.bat，浏览器会自动打开 http://127.0.0.1:5000。

完整版包含：AI 助教答疑、在线代码运行与评分、错题本、笔记与本地文件关联、 思维导图编辑、星海知识图谱、全部 400 节图文讲解。

方式二：在线演示站（免安装，可直接分享给客户）

访问 GitHub Pages 地址即可浏览全部课程内容、练习题与思维导图， 并试听其中的讲解样例（在线站只收录部分讲解，完整版请本地运行）。
