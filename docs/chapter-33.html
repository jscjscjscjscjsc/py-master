04. 33.4 步骤 2：数据层与笔记列表 ▼

33.4.1 js/api.js 要点

API_BASE 用 location.hostname 动态取：本机访问自动是 127.0.0.1，局域网访问自动是服务器 IP，无需改代码：

javascript
const API_HOST = location.hostname || "127.0.0.1";
const API_BASE = "http://" + API_HOST + ":8000/api";

统一封装，错误时抛出 detail 文本（前端可直接展示）：

javascript
async function request(path, options = {}) {
  const resp = await fetch(API_BASE + path, {
    headers: { "Content-Type": "application/json" },
    ...options,
  });
  if (!resp.ok) {
    let detail = `请求失败（${resp.status}）`;
    try {
      const data = await resp.json();
      if (data && data.detail) detail = data.detail;
    } catch (_) {}
    throw new Error(detail);
  }
  if (resp.status === 204) return null;
  return resp.json();
}

易错点：DELETE 接口返回 204 无 body，resp.json() 会抛错——必须先判 204。

33.5.2 marked 自定义渲染器（代码高亮）

javascript
const renderer = new marked.Renderer();
renderer.code = function (code, lang) {
  const language = lang && hljs.getLanguage(lang) ? lang : "plaintext";
  return `<pre><code class="hljs">${hljs.highlight(code, { language }).value}</code></pre>`;
};
marked.setOptions({ renderer, breaks: true });

安全红线：v-html 渲染的必须是消毒后的 HTML——marked 输出先过 DOMPurify.sanitize()，防止笔记内容注入 <script> 等 HTML（XSS）。本地单用户项目风险低，但这是面试必问的就业红线，必须做。

渲染统一走一个方法（编辑预览与问答回答共用）：

javascript
renderMd(text) {
  return DOMPurify.sanitize(marked.parse(text || ""));
}

33.5.3 快捷键与自动保存

javascript
document.addEventListener("keydown", (e) => {
  const ctrl = e.ctrlKey || e.metaKey;
  if (ctrl && e.key.toLowerCase() === "s") { e.preventDefault(); this.saveNote(); }
  if (ctrl && e.key.toLowerCase() === "k") { e.preventDefault(); this.$refs.searchInput.focus(); }
  if (ctrl && e.key.toLowerCase() === "n") { e.preventDefault(); this.newNote(); }
  if (ctrl && e.key.toLowerCase() === "e") {
    e.preventDefault();
    const order = ["edit", "split", "preview"];   // 编辑 → 分屏 → 预览 循环
    this.editorMode = order[(order.indexOf(this.editorMode) + 1) % order.length];
  }
});

编辑器提供编辑 / 分屏 / 预览三态（工具栏按钮 + Ctrl+E 循环）：分屏时左右各占一半，编辑或预览单态时占满整栏，不留白。

自动保存三件套：失焦 @blur="autoSave()"、切换笔记前 autoSaveIfNeeded()、关闭页面 beforeunload 提示未保存。

33.6.2 引用角标与来源卡片

回答中的 [1] 渲染成可点击角标，事件用委托处理（v-html 内容无法直接绑事件）：

javascript
renderAnswer(text) {
  let html = marked.parse(text || "");
  html = html.replace(/\[(\d+)\]/g, '<sup class="cite" data-idx="$1">[$1]</sup>');
  return DOMPurify.sanitize(html);   // v-html 内容必须消毒（XSS 红线）
},
onChatClick(e) {
  const cite = e.target.closest(".cite");
  if (!cite) return;
  const cards = e.target.closest(".chat-msg").querySelectorAll("details.source-card");
  const target = cards[parseInt(cite.dataset.idx, 10) - 1];
  if (target) { target.open = true; target.scrollIntoView({ behavior: "smooth" }); }
}

33.6.3 历史回看

GET /api/chats 返回含来源快照的全部消息，mounted 时加载。提问流程是乐观更新：

  1. 点击发送后立即把用户消息推进 chatMessages 上屏（不等后端），清空输入框；
  2. asking = true 渲染"AI 思考中…"占位气泡（三个跳动圆点，CSS 动画）；
  3. 后端返回后追加 assistant 消息、移除占位、滚动到底部；
  4. 失败兜底：移除占位并展示后端 detail；该条 user 消息仅本地显示（AI 失败时后端未入库，刷新后不保留）。

验证：勾选 1~2 篇笔记提问——输入框立即清空、user 消息马上出现在列表、AI 气泡显示"思考中"，随后回答出现 [1] 角标；点击角标展开来源卡片，点"打开笔记核对"跳到对应笔记。
