02. 25.1 为什么需要前端框架 ▼

25.1.1 概念认知：手写 DOM 的痛点

回顾第 22 章的渲染代码：

js
for (const s of students) {
    const li = document.createElement("li");
    li.textContent = `${s.name}: ${s.score}`;
    list.appendChild(li);
}

数据一变就要手动操作 DOM（创建、修改、删除元素）——代码又长又容易漏。前端框架的答案：声明式渲染——你只声明"页面长什么样"，数据变了框架自动更新页面。

25.1.2 概念认知：声明式 vs 命令式

  • 命令式（手写 DOM）："创建一个 li，塞进 ul"——告诉浏览器怎么做；
  • 声明式（Vue 模板）："这个列表由 students 数据渲染"——告诉框架要什么。

类比：命令式像"你开车，每一步都自己操作"；声明式像"叫车，说目的地就行"。Vue 帮你开车，你只管目的地（数据）。

交叉验证：同一个功能——手写 DOM vs Vue

js
// 手写 DOM（命令式）：每一步都要自己操作
const li = document.createElement("li");
li.textContent = `${s.name}: ${s.score}`;
list.appendChild(li);
// 数据变了：还要手动找到元素、改内容
html
<!-- Vue（声明式）：只说"列表由 students 渲染"，数据变自动更新 -->
<li v-for="s in students">{{ s.name }}：{{ s.score }}</li>

讲解：手写 DOM 是"命令式"（告诉浏览器每一步怎么做），Vue 是"声明式"（告诉框架要什么结果）。数据变化时，手写版要自己找元素、改内容；Vue 自动完成——这就是框架存在的意义。

03. 25.2 Vue 3 CDN 起步 ▼

25.2.1 语法掌握：创建第一个 Vue 应用

代码案例 25.1：CDN 引入 + 创建应用（✅ 正确）

html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>Vue 入门</title>
    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
</head>
<body>
    <div id="app">
        <h1>{{ message }}</h1>
    </div>

    <script>
        const { createApp } = Vue;

        createApp({
            data() {
                return {
                    message: "你好，Vue！",
                };
            },
        }).mount("#app");
    </script>
</body>
</html>

讲解：

  • CDN 引入 Vue（不装任何东西，一个 HTML 文件就能跑——本课程的学习方式）；
  • createApp({...}).mount("#app")：创建应用并挂载到 #app 元素；
  • data() 返回的数据成为页面可用的"响应式数据"；
  • {{ message }}：插值——显示 message 的值；message 一变，页面自动更新（这就是声明式）。

25.2.2 语法掌握：数据绑定

代码案例 25.2：响应式演示（✅ 正确）

html
<div id="app">
    <p>{{ name }} 今年 {{ age }} 岁</p>
    <p>明年 {{ age + 1 }} 岁</p>
</div>

<script>
    const { createApp } = Vue;
    createApp({
        data() {
            return { name: "张三", age: 19 };
        },
    }).mount("#app");
</script>

讲解：{{ }} 里可以是表达式（age + 1）；data 里的数据变化时，所有用到它的地方自动刷新——不需要手动操作 DOM。

原理探秘：Vue 的响应式原理（了解）

Vue 3 用 Proxy 包装 data() 返回的对象：读取属性时"收集"谁在用（依赖收集），修改属性时"通知"所有用到它的地方重新渲染。所以你在 data() 里声明、在模板里使用，数据一变页面就动——这一切由框架替你完成，你只需要改数据。

04. 25.3 四个核心指令 ▼

指令 = 模板里以 v- 开头的特殊属性，让 HTML 拥有"逻辑能力"。

25.3.1 v-for：列表渲染

代码案例 25.3：渲染学生列表（✅ 正确）

html
<div id="app">
    <ul>
        <li v-for="s in students" :key="s.id">
            {{ s.name }}：{{ s.score }}
        </li>
    </ul>
</div>

<script>
    const { createApp } = Vue;
    createApp({
        data() {
            return {
                students: [
                    { id: 1, name: "张三", score: 88 },
                    { id: 2, name: "李四", score: 95 },
                ],
            };
        },
    }).mount("#app");
</script>

讲解：v-for="s in students" 遍历数组（相当于 Python 的 for s in students）；:key 给每个元素唯一标识（Vue 高效更新的依据）。数据里加一个学生，页面自动多一行——这就是声明式。

25.3.2 v-if：条件渲染

代码案例 25.4：及格判断（✅ 正确）

html
<p v-if="score >= 60">及格</p>
<p v-else>不及格</p>

讲解：v-if / v-else 根据条件显示不同内容——和 Python 的 if/else 一个思路。

25.3.3 v-on：事件处理

代码案例 25.5：点击计数（✅ 正确）

html
<div id="app">
    <p>点击了 {{ count }} 次</p>
    <button @click="count++">点我</button>
</div>

<script>
    const { createApp } = Vue;
    createApp({
        data() {
            return { count: 0 };
        },
    }).mount("#app");
</script>

讲解：@click 是 v-on:click 的简写——点击时执行表达式（第 22 章 addEventListener 的 Vue 版）。count++ 改数据，页面自动更新。

25.3.4 v-model：双向绑定

代码案例 25.6：输入框与数据同步（✅ 正确）

html
<div id="app">
    <input v-model="keyword" placeholder="输入关键词">
    <p>你输入的是：{{ keyword }}</p>
</div>

讲解：v-model 让输入框和数据双向同步——你输入，keyword 自动更新；keyword 变化，页面自动刷新。这是"表单"场景的利器。

05. 25.4 组件化思想 ▼

25.4.1 概念认知：组件 = 可复用的"零件"

组件（component） 是把"一块界面 + 它的逻辑"打包成可复用的零件：

页面 = 导航组件 + 学生卡片组件 + 输入框组件 + 页脚组件

为什么组件化：

  1. 复用：学生卡片写一次，列表里每个学生都用它；
  2. 分工：每人负责一个组件，互不冲突；
  3. 维护：改卡片样式只改一个组件。

25.4.2 了解：单文件组件

真实 Vue 项目用 .vue 文件（模板 + 样式 + 逻辑写在一个文件），配合 Vite 打包工具。本课程用 CDN 方式理解概念，最终项目也以 CDN 起步，Vite 工程化了解即可（可在就业后深入学习）。

06. 25.5 综合案例：Vue + FastAPI 前后端联调 ▼

25.5.1 综合运用：待办清单联调页面

前端页面（Vue）用 fetch 调用第 24 章的 FastAPI 接口，把数据渲染成列表——这就是前后端分离的完整闭环（第 21 章架构落地）。

代码案例 25.7：待办清单页面（✅ 正确）

html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>待办清单</title>
    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
    <style>
        .done { text-decoration: line-through; color: gray; }
    </style>
</head>
<body>
    <div id="app">
        <h1>待办清单</h1>
        <input v-model="newContent" placeholder="新任务">
        <button @click="addTask">添加</button>

        <ul>
            <li v-for="task in tasks" :key="task.id">
                <span :class="{ done: task.done }">{{ task.content }}</span>
            </li>
        </ul>
    </div>

    <script>
        const { createApp } = Vue;

        createApp({
            data() {
                return {
                    tasks: [],
                    newContent: "",
                };
            },
            methods: {
                async loadTasks() {
                    const resp = await fetch("http://127.0.0.1:8000/api/tasks");
                    const data = await resp.json();
                    this.tasks = data.data;
                },
                async addTask() {
                    await fetch("http://127.0.0.1:8000/api/tasks", {
                        method: "POST",
                        headers: { "Content-Type": "application/json" },
                        body: JSON.stringify({ content: this.newContent }),
                    });
                    this.newContent = "";
                    this.loadTasks();
                },
            },
            mounted() {
                this.loadTasks();
            },
        }).mount("#app");
    </script>
</body>
</html>

讲解：

  • mounted()：页面加载完成时自动调用（初始化加载数据）；
  • methods：页面用的事件/逻辑函数；
  • loadTasks 用 fetch 调 FastAPI（第 24 章的接口），this.tasks = data.data 更新数据 → Vue 自动重渲染列表；
  • addTask POST 新任务后重新加载——数据流：页面 → API → 数据库 → API → 页面；
  • 前提：FastAPI 已开 CORS（第 24.5 节），否则浏览器拦截。

08. 25.7 本章 Debug 四件套 ▼

问题 1：页面空白 + 控制台报 createApp 未定义

问题代码：

html
<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>

实际表现：Vue is not defined。

提示：CDN 加载成功了吗？Network 面板看 script 请求状态？

讲解：CDN 链接拼错、没联网、被墙，都会导致 Vue 没加载。F12 → Network → 看 vue.global.js 请求是否 200；也可以换成可访问的 CDN 镜像。

问题 2：data 忘记 return

问题代码：

js
data() {
    message: "你好"      // 少了 return
}

实际表现：页面空白或报错。

提示：data 是个函数，要返回什么？

讲解：data() 必须 return {...}——Vue 要求 data 是"返回数据对象的函数"，这样每个组件实例才有独立数据。

问题 3：v-for 列表不更新

问题描述：直接给数组赋值，页面没变。

提示：Vue 的响应式对"整体赋值"和"修改元素"处理一样吗？

讲解：Vue 能侦测"整体赋值"（this.tasks = ...），但某些数组操作（如 this.tasks[0] = x 按索引改）可能不触发更新——习惯用整体赋值或 push 等数组方法。

问题 4：fetch 报 CORS

问题描述：Vue 页面调 FastAPI 报 CORS 错误。

提示：后端加过 CORSMiddleware 吗？域名端口匹配吗？

讲解：CORS 是后端的事——FastAPI 加 allow_origins=["*"]（开发期）就解决（第 24.5 节）。前后端联调先确认后端 CORS 已开。

010. 25.9 本章小结与知识树 ▼

知识树：

Vue 入门
├── 为什么：声明式渲染替代手动 DOM（数据驱动页面）
├── 起步：CDN 引入 + createApp({data() {...}}).mount("#app")
│   └── {{ }} 插值；data 变化 → 页面自动更新
├── 四大指令
│   ├── v-for：列表渲染（:key 唯一标识）
│   ├── v-if / v-else：条件渲染
│   ├── v-on（@click）：事件处理
│   └── v-model：表单双向绑定
├── 组件：可复用的"界面+逻辑"零件（单文件组件 .vue 了解）
├── 联调：mounted 加载 + fetch 调 FastAPI + methods 事件
│   └── 数据流：页面 → API → 数据库 → API → 页面
└── Vite：工程化工具（了解）

必须记住的 5 件事：

  1. data() 必须 return {}；{{ }} 里可以放表达式；
  2. v-for 渲染列表要写 :key；
  3. @click = v-on:click，事件里改数据页面自动更新；
  4. v-model 是双向绑定（表单输入与数据同步）；
  5. 联调三件套：后端开 CORS + 前端 fetch + Network 面板验证。
