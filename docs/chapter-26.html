02. 26.1 pandas：表格数据处理的"Excel 版 Python" ▼

26.1.1 概念认知：DataFrame 是什么

pandas 是 Python 数据分析的核心库，核心数据结构 DataFrame——可以理解为"带表头和索引的 Excel 表格"。

代码案例 26.1：安装（✅ 正确）

powershell
pip install pandas matplotlib

原理探秘：DataFrame 为什么快

DataFrame 底层按列存储，核心运算（求和、分组）由 C 语言实现并向量化——一次处理整列，而不是逐行循环。所以 df.groupby(...).sum() 比 Python 手写循环快几十上百倍。把循环交给 C，把意图留给自己——这是 pandas 的设计哲学，也是你学它时要放弃"手写循环"习惯的原因。

26.1.4 了解：NumPy 数组——pandas 的底层

概念认知：pandas 的 DataFrame 底层由 NumPy 数组支撑。NumPy 的核心是 ndarray（多维数组）——可以理解成"支持数学运算的超级列表"。

代码案例 26.4：NumPy 基础（✅ 正确，实测过）

python
import numpy as np

arr = np.array([1, 2, 3, 4])

print(arr + 1)            # 每个元素 +1
print(arr * 2)            # 每个元素 ×2
print(arr.shape)          # 形状（几维、每维几个）
print(arr.dtype)          # 元素类型
print(arr.mean(), arr.max(), arr.sum())
print(arr[arr > 2])       # 布尔索引：筛选大于 2 的元素

matrix = np.array([[1, 2, 3], [4, 5, 6]])
print(matrix.shape)
print(matrix[1, 2])       # 第 2 行第 3 列

运行结果：

[2 3 4 5]
[2 4 6 8]
(4,)
int64
2.5 4 10
[3 4]
(2, 3)
6

讲解：

  • arr + 1 给每个元素加 1——这叫向量化运算；
  • arr[arr > 2] 是布尔索引：一次筛选出所有满足条件的元素（不用写循环）；
  • matrix[1, 2] 是二维数组的索引写法（第 5 章二维列表的 NumPy 版）。

交叉验证：Python 列表循环 vs NumPy 向量化

python
# 列表：要写循环
data = list(range(1, 1000001))
result = [x * 2 for x in data]        # Python 循环

# NumPy：一行，C 语言实现
import numpy as np
arr = np.arange(1, 1000001)
result2 = arr * 2                     # 向量化

讲解：向量化把"逐元素循环"交给 C 语言——代码更短、速度更快（第 12 章"把循环交给 C，把意图留给自己"的 pandas 版）。工作里 pandas 处理不了的底层数值运算，就用 NumPy。

就业红线（了解级边界）：NumPy 这里只是"认识"；数据分析岗位要求会用 NumPy 做数组运算、索引切片、统计函数，并能说清"NumPy 与 pandas 的关系"（pandas 构建在 NumPy 之上）。进阶路径：学完本教材第 26 章后，用官方教程把 NumPy 的索引/切片/广播过一遍。

26.3.2 概念认知：合规边界（红线）

爬虫必须在法律与网站规则内使用：

  1. 遵守 robots.txt：网站声明"哪些不能爬"；
  2. 控制频率：高频请求 = 攻击服务器，可能违法；
  3. 只取公开数据：登录后数据、个人隐私不可爬；
  4. 不用于商业竞争/倒卖。

就业提示：爬虫是 Python 热门方向，但合规比技术重要——面试问"爬虫的注意事项"，先答"robots、频率、公开数据、法律边界"。

26.3.3 语法掌握：合规爬虫实战

把旧课件"伪装浏览器爬 CSDN"的代码改造为合规演示版——保留工程技巧（Session/UA 轮换/重试/超时），去掉"绕过反爬"的取向，解析演示用本地 HTML（不依赖网络，课堂可跑）。

代码案例 26.7：合规爬虫骨架（✅ 正确，实测过）

python
import random
import time
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

USER_AGENTS = [
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/91.0.4472.124 Safari/537.36",
    "Mozilla/5.0 (X11; Linux x86_64) Firefox/90.0",
    "Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7) Safari/605.1.15",
]

def browse_url(url, retries=3, timeout=10):
    """合规请求：随机 UA + 失败重试 + 超时 + 编码处理"""
    session = requests.Session()
    session.headers["User-Agent"] = random.choice(USER_AGENTS)

    retry = Retry(
        total=retries,
        backoff_factor=1,
        status_forcelist=[429, 500, 502, 503, 504],
        allowed_methods=["GET"],
    )
    session.mount("https://", HTTPAdapter(max_retries=retry))

    try:
        resp = session.get(url, timeout=timeout)
        resp.raise_for_status()
        if not resp.encoding or resp.encoding == "ISO-8859-1":
            resp.encoding = resp.apparent_encoding
        time.sleep(0.5)      # 限频：请求间隔，别打爆服务器
        return resp.text
    except requests.exceptions.RequestException as e:
        print(f"请求异常：{e}")
        return ""

讲解（每个技巧的"为什么"）：

  • Session：复用连接，效率高；
  • User-Agent 轮换：标识客户端身份（不是"伪装绕过"），UA 是礼貌的请求头；
  • Retry：429/5xx 自动重试，backoff_factor=1 递增等待——第 12 章 @retry 的 requests 版；
  • timeout：请求必须有超时（第 13 章教训）；apparent_encoding 修复中文乱码；
  • time.sleep(0.5) 限频：爬虫的第一礼仪。

代码案例 26.8：解析本地 HTML（✅ 正确，实测过）

python
from bs4 import BeautifulSoup

html = """
<html><body>
  <p class="book">Python 编程</p>
  <p class="book">Java 编程</p>
  <a href="link1.html">链接1</a>
  <ul id="menu"><li>首页</li><li>产品</li></ul>
</body></html>
"""

soup = BeautifulSoup(html, "html.parser")

print([p.text for p in soup.find_all("p", class_="book")])
print([a.get("href") for a in soup.select("a")])
print([li.text for li in soup.select("#menu li")])

运行结果：

['Python 编程', 'Java 编程']
['link1.html']
['首页', '产品']

讲解：find_all(标签, class_=...) 按标签+属性找；select(CSS 选择器) 更灵活（#menu li = id 为 menu 的节点下的 li）。真实用法：browse_url(网址) 拿到 HTML → BeautifulSoup 解析 → 提取标题/正文/链接。
