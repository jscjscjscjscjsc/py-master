02. 10.1 概念认知：从字典到类 ▼

10.1.1 用字典表示学生的痛点

第 6 章我们用字典存学生信息：

python

它有两个问题：

  1. 键名靠自觉：有人写 "name"，有人写 "Name"，一拼错就 KeyError；
  2. 行为散落：算平均分、改年龄的逻辑散在各处，每个用到的人都要重写一遍。

10.1.2 概念认知：类 = 数据 + 行为的模板

类（class） 把"学生有什么（属性：姓名、年龄、成绩）"和"学生会做什么（方法：介绍、算平均分）"打包成一个模板。根据模板造出来的具体个体叫对象（object）/实例（instance）。

类比：类 = 图纸，对象 = 按图纸造出来的房子。一张图纸能造无数栋房子，每栋的家具（数据）不同。

04. 10.3 __init__ 与实例属性 ▼

10.3.1 语法掌握：构造方法 __init__

代码案例 10.3：用 __init__ 初始化（✅ 正确，标准写法）

python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        return f"我是{self.name}，今年{self.age}岁"


s1 = Student("张三", 19)
s2 = Student("李四", 20)

print(s1.name)
print(s1.introduce())
print(s2.introduce())

运行结果：

张三
我是张三，今年19岁
我是李四，今年20岁

讲解：

  • __init__ 是构造方法：创建对象时自动调用，负责初始化属性；
  • self 代表"正在创建的这个对象本身"——self.name = name 意思是"把传入的 name 存到我自己身上"；
  • 一个类可以创建任意多个对象，每个对象的属性独立。

原理探秘：self 到底是什么？

s1.introduce() 调用时，Python 自动把 s1 传给第一个参数 self。所以：

python
s1.introduce()
# 等价于
Student.introduce(s1)

self 不是关键字（换成 this、me 也能跑），但行业铁律是叫 self。它的本质是"方法访问'自己'的通行证"——没有它，方法就不知道操作哪个对象的数据。

交叉验证：忘写 self / 忘传参数

❌ 错误 1：方法里忘写 self

python
class Student:
    def __init__(self, name):
        self.name = name
    def introduce():          # 少了 self
        return f"我是{self.name}"

s1 = Student("张三")
print(s1.introduce())

实际报错：

TypeError: introduce() takes 0 positional arguments but 1 was given

讲解：调用 s1.introduce() 时 Python 会把 s1 传进去，但函数没声明 self 接——"给了 1 个参数但函数只收 0 个"。类的方法第一个参数必须是 self。

❌ 错误 2：创建对象时忘传参数

python
s1 = Student()

实际报错：

TypeError: Student.__init__() missing 2 required positional arguments: 'name' and 'age'

讲解：__init__ 声明了两个必填参数，Student() 不传就报错。__init__ 的参数 = 创建对象时必须提供的信息——这就是类的"接口契约"。

05. 10.4 三种方法：实例方法、类方法、静态方法 ▼

10.4.1 概念认知：方法 = 属于类的函数

代码案例 10.4：三种方法对比（✅ 正确）

python
class Util:
    version = "1.0"

    def instance_method(self):
        return f"实例方法，访问 self：{self}"

    @classmethod
    def class_method(cls):
        return f"类方法，版本 {cls.version}"

    @staticmethod
    def static_method(a, b):
        return f"静态方法，和普通函数一样：{a + b}"


u = Util()
print(u.instance_method())
print(Util.class_method())
print(Util.static_method(3, 4))

运行结果：

实例方法，访问 self：<__main__.Util object at 0x...>
类方法，版本 1.0
静态方法，和普通函数一样：7

讲解：

  • 实例方法：第一个参数 self，操作具体对象的数据（最常用）；
  • 类方法：用 @classmethod 装饰，第一个参数 cls（类本身），操作类变量，不需要对象就能调用；
  • 静态方法：用 @staticmethod 装饰，既不收 self 也不收 cls，就是放在类里的普通函数（按主题归类用）。

原理探秘：什么时候用哪种？

  • 方法需要读/写某个对象的数据 → 实例方法（self）；
  • 方法需要读/写类级别的数据（如总实例数、全局配置）→ 类方法（cls）；
  • 方法跟类只是"主题相关"、不碰任何数据 → 静态方法。

判断口诀：有 self 管个体，有 cls 管集体，都没有管工具。

交叉验证：实例方法能通过类调用吗？

python
Util.instance_method(u)    # 手动传对象，可以
Util.instance_method()     # 不传对象，报错

讲解：类名.实例方法(对象) 等价于 对象.实例方法()；但不传对象就报 TypeError: instance_method() missing 1 required positional argument: 'self'。实例方法必须绑定到一个对象上使用。

06. 10.5 封装：把内部藏起来 ▼

10.5.1 概念认知：封装是什么

封装（encapsulation） 是面向对象的三大特性之一：把数据藏在对象内部，只提供受控的方法给外部使用。

比如银行账户：余额是核心数据。如果外部能随便 acct.balance = -100，账户就乱套了。封装的做法：余额私有，存取款必须走方法，方法里做校验。

10.5.2 语法掌握：私有属性（名称改写）

代码案例 10.5：私有属性与访问方法（✅ 正确）

python
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance      # 双下划线开头 = 私有

    def deposit(self, amount):
        self.__balance += amount
        return self.__balance

    def get_balance(self):
        return self.__balance


acct = BankAccount(1000)
print(acct.get_balance())
print(acct.deposit(500))

运行结果：

1000
1500

交叉验证：外部直接访问私有属性

python
print(acct.__balance)

实际报错：

AttributeError: 'BankAccount' object has no attribute '__balance'

讲解：双下划线开头的属性会被名称改写（name mangling）——Python 在内部把它改名为 _BankAccount__balance。所以外部直接写 acct.__balance 找不到。注意：

python
print(acct._BankAccount__balance)   # 仍然能访问（1000）

原理探秘：私有是"约定"不是"铁壁"

Python 没有真正的 private——_BankAccount__balance 还是能访问到。私有机制的意义不是"防黑客"，而是明确告诉开发者：这是内部细节，别碰。真要去碰（调试、测试），后果自负。这符合 Python 哲学：我们是成年人，靠约定自律。

10.5.3 语法掌握：私有方法

方法同样可以私有（def __secret(self)），外部不能直接调用。内部逻辑的"辅助步骤"适合私有——外面只关心主方法，不关心你内部怎么拆步骤。

10.5.4 语法掌握：@property——把方法变成属性

场景：私有属性要提供 get_age() / set_age() 两个方法。但 Python 有更优雅的写法：用 @property 装饰器把方法变成属性——调用时不加括号。

代码案例 10.6：@property 校验（✅ 正确，实测过）

python
class Human:
    def __init__(self, name, age):
        self.__name = name
        self.__age = age

    @property
    def age(self):
        """像属性一样读取"""
        return self.__age

    @age.setter
    def age(self, value):
        """像属性一样赋值，但带校验"""
        if value <= 0 or value > 100:
            raise ValueError("年龄必须在 1-100 之间")
        self.__age = value


h = Human("张三", 18)
print(h.age)      # 不加括号！
h.age = 20
print(h.age)

try:
    h.age = -5
except ValueError as e:
    print("捕获：", e)

运行结果：

18
20
捕获： 年龄必须在 1-100 之间

交叉验证：getter/setter 写法 vs @property 写法

python
# 方式一：Java 风格 getter/setter（教材 10.5.2 的写法）
print(h.get_age())
h.set_age(20)

# 方式二：@property（Python 风格）
print(h.age)
h.age = 20

讲解：两者实现同样的功能，但 @property 让调用方"像操作普通属性一样"（不加括号）——更符合 Python 的简洁哲学。校验逻辑写在 @age.setter 里，赋值时自动触发。

原理探秘：property 本质是装饰器

@property 就是第 12 章要学的装饰器的具体应用：它把一个方法包装成"属性访问"——读 h.age 时自动调用被 @property 装饰的方法，写 h.age = x 时自动调用被 @age.setter 装饰的方法。先记住用法，第 12 章学完装饰器后回头看，会发现它们是同一件事。

就业提示：Python 里"私有属性 + @property"是标准封装姿势，和 Java 的 getter/setter 对应但更简洁。面试问"Python 怎么实现属性校验"，答 @property + @setter 即可。

07. 10.6 类变量与实例变量 ▼

10.6.1 概念认知：两种"属于"不同层级的数据

  • 类变量：写在类体里，所有对象共享一份；
  • 实例变量：写在 __init__ 里（self.xxx），每个对象各有一份。

代码案例 10.7：类变量计数（✅ 正确）

python
class Counter:
    total = 0                     # 类变量：所有对象共享

    def __init__(self):
        Counter.total += 1        # 每创建一个对象 +1


c1 = Counter()
c2 = Counter()
c3 = Counter()

print(Counter.total)

运行结果：

3

讲解：total 是"类级别"的计数——不管哪个对象创建，都往类的 total 上加。真实场景：统计类创建了多少对象、全局配置项。

交叉验证：c1.total = 100 发生了什么

python
c1.total = 100        # 给 c1 创建了一个"实例变量 total"

08. 10.7 魔术方法：让对象"会说话" ▼

魔术方法（magic methods） 是名字被双下划线包围、由 Python 自动调用的方法（__init__ 你已经见过了）。本节学三个最常用的。

10.7.1 语法掌握：__str__ 与 __repr__

代码案例 10.8：自定义显示（✅ 正确）

python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"({self.x}, {self.y})"

    def __repr__(self):
        return f"Point({self.x}, {self.y})"


p = Point(1, 2)
print(str(p))
print(repr(p))
print(p)

运行结果：

(1, 2)
Point(1, 2)
(1, 2)

讲解：

  • __str__：print(对象)、str(对象) 时调用——给人看的友好格式；
  • __repr__：repr(对象)、交互模式直接输入对象名时调用——给开发者看的精确格式；
  • print(p) 用的是 __str__。

原理探秘：为什么要有两个？

行业约定：__str__ 面向最终用户（"张三，19岁"），__repr__ 面向开发者调试（"Student('张三', 19)"——最好能直接复制回代码里重建这个对象）。写类时至少实现 __repr__——调试时打印对象才看得懂。

10.7.2 语法掌握：__eq__ 判断相等

代码案例 10.9：自定义相等（✅ 正确）

python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y


p1 = Point(1, 2)
p2 = Point(1, 2)
p3 = Point(3, 4)

print(p1 == p2)
print(p1 == p3)

运行结果：

True
False

讲解：默认情况下 p1 == p2 比较的是内存地址（两个对象即使内容相同也不相等）。实现 __eq__ 后，改为比较内容。真实场景：坐标、配置项、订单快照需要"按内容比较"时都用它。

10.7.3 综合运用：MagicBox——魔法函数全家桶

魔法函数的威力在于：你定义一次，Python 的语法就能直接作用于你的对象。用一个"魔法盒子"类一次展示 8 个：

代码案例 10.10：MagicBox（✅ 正确，修正版，实测过）

python
class MagicBox:
    def __init__(self, items):
        self.items = list(items) if items is not None else []

    def __str__(self):
        return str(self.items)

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __setitem__(self, key, value):
        self.items[key] = value

    def __delitem__(self, key):
        del self.items[key]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

    def __add__(self, other):
        if isinstance(other, MagicBox):
            return MagicBox(self.items + other.items)
        raise TypeError("只能与 MagicBox 相加")

    def __eq__(self, other):
        return isinstance(other, MagicBox) and self.items == other.items


box = MagicBox([1, 2, 3])
print(box)          # __str__
print(len(box))     # __len__
print(box[0])       # __getitem__
box[0] = 10         # __setitem__
print(box[0])
del box[0]          # __delitem__
print(box)
print(4 in box)     # __contains__
print([x for x in box])   # __iter__：支持 for 循环

box2 = MagicBox([4, 5])
print(box + box2)   # __add__：两个盒子相加

运行结果：

[1, 2, 3]
3
1
10
[2, 3]
False
[2, 3]
[2, 3, 4, 5]

讲解（每个魔法函数管一个"语法"）：

魔法函数触发的语法作用
__str__print(box)显示内容
__len__len(box)长度
__getitem__box[0]按下标取值
__setitem__ / __delitem__box[0]=x / del box[0]按下标改/删
__contains__4 in box成员判断
__iter__for x in box支持遍历
__add__box + box2定义"相加"的含义（运算符重载）
__eq__box == box2定义"相等"

原理探秘：运算符重载

box + box2 之所以成立，是因为你定义了 __add__——运算符 + 对自定义对象的行为由你自己决定（第 2 章"字符串也能用 +"的同一个机制）。同理 __lt__ 定义 <、__mul__ 定义 *。这就是为什么 Python 能"一个运算符、无数种含义"。

修正说明：某些教材里 __next__ 和 __iter__ 混在一起写，会出现"每次 next 都返回第一个元素"的 bug。正确做法：__iter__ 返回 iter(self.items)，把迭代细节交给内置迭代器，不要在类里自己维护 next 状态（除非你写的是真正的迭代器类，第 12 章讲）。

就业提示：面试问"Python 的运算符重载"，答"定义 __add__ 等双下划线方法即可"；再补一句"数据类、向量、坐标类都会用到"，就是加分项。

class BankAccount:
    def __init__(self, balance):
        self.__balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError(f"存款金额必须大于 0，收到 {amount}")
        self.__balance += amount
        return self.__balance

    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError(f"取款金额必须大于 0，收到 {amount}")
        if amount > self.__balance:
            return False
        self.__balance -= amount
        return self.__balance

    def get_balance(self):
        return self.__balance

acct = BankAccount(1000)
try:
    acct.deposit(-100)
except ValueError as e:
    print("操作被拒绝：", e)

print(acct.get_balance())   # 余额没变，还是 1000

1000

012. 10.11 本章小结与知识树 ▼

知识树：

类与封装
├── 思想：类 = 数据 + 行为 的模板；对象 = 按模板造的个体（图纸 vs 房子）
├── 类与对象：class Student: / Student() 实例化；类名大驼峰
├── __init__：构造方法，创建时自动调用；参数 = 出生必填信息
├── self：代表当前对象；s.introduce() == Student.introduce(s)
├── 三种方法
│   ├── 实例方法（self）：管个体数据（最常用）
│   ├── 类方法 @classmethod（cls）：管集体数据
│   └── 静态方法 @staticmethod：放类里的普通函数
├── 封装
│   ├── 私有属性 __x：名称改写 _Class__x（约定非铁壁）
│   ├── 私有方法 __y：内部辅助步骤
│   └── 公开接口方法：get_balance / deposit（带校验）
├── 类变量 vs 实例变量：共享一份 vs 每人一份；实例赋值会遮蔽
└── 魔术方法：__str__（给人看）/ __repr__（给开发者看）/ __eq__（按内容比）

必须记住的 5 件事：

  1. 类方法第一个参数是 self，漏掉就报"takes 0 positional arguments but 1 was given"；
  2. __init__ 的参数 = 创建对象必填的信息；
  3. 私有属性是双下划线开头（名称改写），但只是约定不是铁壁；
  4. 类变量所有对象共享；对象.类变量 = 值 只创建实例变量并遮蔽；
  5. __str__ 给用户看、__repr__ 给开发者看、__eq__ 定义"相等"的含义。
