02. 3.1 先理解 RAG 的责任边界 ▼

RAG 是 Retrieval-Augmented Generation，即“检索增强生成”。系统先从受控知识库中检索证据，再把证据与问题一起交给模型生成答案。

flowchart TD
    subgraph Offline[离线索引阶段]
        A[企业文档] --> B[解析清洗]
        B --> C[切块]
        C --> D[Embedding]
        D --> E[(向量库)]
    end
    subgraph Online[在线问答阶段]
        Q[用户问题] --> QE[问题向量]
        QE --> R[多路召回]
        E --> R
        R --> RR[重排]
        RR --> P[组装证据与提示词]
        P --> L[LLM 生成]
        L --> O[答案、引用、置信信息]
    end

RAG 可以缓解：

  • 模型训练数据中没有企业私有知识。
  • 模型知识存在时间截止点。
  • 回答缺少可核查证据。
  • 频繁微调带来的成本和更新困难。

RAG 不能自动解决：

  • 源文档本身错误或互相矛盾。
  • 解析漏字、切块破坏语义、检索召回错误。
  • 提示词注入和越权读取。
  • 模型忽略证据或错误归纳。

课堂判断句：RAG 的答案上限由知识库质量决定，答案下限由检索和生成护栏决定。

03. 3.2 Day 11｜RAG 原理与文档加载 ▼

3.2.1 当日问题与验收

当日问题：不同格式的文件怎样变成统一、可追踪的文本数据？

验收要求：

  • 成功解析 PDF、Word、HTML 各一份。
  • 每条输出包含 source、page 或 section、loader。
  • 输出文档数、总字符数、空文档数和异常列表。
  • 扫描版 PDF 能被识别为空文本或低文本量，不能悄悄入库。

3.2.2 统一文档对象

python
from dataclasses import dataclass, field
from typing import Any


@dataclass(frozen=True)
class Document:
    text: str
    metadata: dict[str, Any] = field(default_factory=dict)


def normalize_text(text: str) -> str:
    lines = [line.strip() for line in text.replace("\u3000", " ").splitlines()]
    return "\n".join(line for line in lines if line)

逐行讲解：

  • dataclass 让对象结构明确，打印和测试更方便。
  • metadata 保存溯源信息，不要把文件名拼进正文干扰检索。
  • replace("\u3000", " ") 统一中文全角空格。
  • 清理空行时要谨慎。表格和代码的换行可能承载结构，生产项目应按文档类型使用不同清洗器。

3.2.3 三种格式加载器

python
from pathlib import Path
from bs4 import BeautifulSoup
import pymupdf
from docx import Document as WordDocument


def load_pdf(path: Path) -> list[Document]:
    items: list[Document] = []
    with pymupdf.open(path) as pdf:
        for page_index, page in enumerate(pdf):
            text = normalize_text(page.get_text("text"))
            if text:
                items.append(Document(
                    text=text,
                    metadata={
                        "source": path.name,
                        "page": page_index + 1,
                        "loader": "pymupdf",
                    },
                ))
    return items


def load_docx(path: Path) -> list[Document]:
    doc = WordDocument(path)
    paragraphs = [normalize_text(p.text) for p in doc.paragraphs]
    text = "\n".join(p for p in paragraphs if p)
    return [Document(text, {"source": path.name, "loader": "python-docx"})] if text else []


def load_html(path: Path) -> list[Document]:
    html = path.read_text(encoding="utf-8")
    soup = BeautifulSoup(html, "html.parser")
    for tag in soup(["script", "style", "nav", "footer"]):
        tag.decompose()
    text = normalize_text(soup.get_text("\n"))
    title = normalize_text(soup.title.get_text()) if soup.title else ""
    return [Document(text, {
        "source": path.name,
        "title": title,
        "loader": "beautifulsoup",
    })] if text else []


LOADERS = {".pdf": load_pdf, ".docx": load_docx, ".html": load_html, ".htm": load_html}


def load_file(path: Path) -> list[Document]:
    loader = LOADERS.get(path.suffix.lower())
    if loader is None:
        raise ValueError(f"不支持的格式: {path.suffix}")
    return loader(path)

关键讲解：

  • 每页 PDF 单独形成 Document，可保留页码引用。
  • Word 示例先处理段落。真实项目还要单独处理表格、页眉页脚和图片文字。
  • HTML 主动去除脚本、样式和导航，减少页面模板噪声。
  • LOADERS 是一个分发表。新增 Markdown 加载器时不需要改 load_file 的控制流。

04. 3.3 Day 12｜Chunking：把长文档切成可检索单元 ▼

3.3.1 为什么不能整篇入库

整篇文档向量只表达“总体主题”，难以定位局部事实；块过小又会丢失上下文。切块需要在“定位精度、语义完整、上下文成本”之间取舍。

3.3.2 固定窗口切块

python
def fixed_chunks(text: str, size: int = 500, overlap: int = 80) -> list[str]:
    if size <= 0:
        raise ValueError("size 必须大于 0")
    if not 0 <= overlap < size:
        raise ValueError("overlap 必须满足 0 <= overlap < size")

    chunks: list[str] = []
    step = size - overlap
    for start in range(0, len(text), step):
        chunk = text[start:start + size].strip()
        if chunk:
            chunks.append(chunk)
        if start + size >= len(text):
            break
    return chunks

逐行讲解：

  • step = size - overlap 决定窗口每次前进多少。
  • overlap 保留边界两侧的上下文，但会增加索引量和重复召回。
  • 最后的 break 防止文本末尾产生多个高度重复的短块。
  • 字符数不等于 token 数。入门课先用字符建立直觉，生产项目应使用目标模型的 tokenizer。

3.3.3 基于段落的递归切块

python
def recursive_chunks(
    text: str,
    max_size: int = 500,
    separators: tuple[str, ...] = ("\n\n", "\n", "。", "；", "，"),
) -> list[str]:
    text = text.strip()
    if not text:
        return []
    if len(text) <= max_size:
        return [text]
    if not separators:
        return fixed_chunks(text, max_size, 0)

    separator, *rest = separators
    parts = text.split(separator)
    if len(parts) == 1:
        return recursive_chunks(text, max_size, tuple(rest))

    output: list[str] = []
    buffer = ""
    for part in parts:
        candidate = f"{buffer}{separator}{part}".strip(separator) if buffer else part
        if len(candidate) <= max_size:
            buffer = candidate
        else:
            if buffer:
                output.extend(recursive_chunks(buffer, max_size, tuple(rest)))
            buffer = part
    if buffer:
        output.extend(recursive_chunks(buffer, max_size, tuple(rest)))
    return output

递归策略先尝试大边界，再退化到小边界。它比硬切字符更容易保留段落和句子，但仍不等于真正的语义切块。

3.3.4 给块增加稳定 ID

python
from hashlib import sha256


def make_chunk(doc: Document, text: str, index: int) -> Document:
    raw_id = f"{doc.metadata.get('source')}|{doc.metadata.get('page')}|{index}|{text}"
    chunk_id = sha256(raw_id.encode("utf-8")).hexdigest()[:16]
    return Document(text=text, metadata={**doc.metadata, "chunk_id": chunk_id, "chunk_index": index})

稳定 ID 的价值：重复入库时可以更新而非无限新增；评测报告也能精确指出命中的证据块。

05. 3.4 Day 13｜Embedding 与向量数据库 ▼

3.4.1 从关键词到语义向量

Embedding 将文本映射为定长向量。语义相近的文本在向量空间中通常更接近。课程使用余弦相似度：

$$ \cos(\theta)=\frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|_2\|\mathbf{b}\|_2} $$

3.4.2 手写余弦相似度

python
from math import sqrt


def cosine_similarity(a: list[float], b: list[float]) -> float:
    if len(a) != len(b) or not a:
        raise ValueError("向量必须非空且维度一致")
    dot = sum(x * y for x, y in zip(a, b))
    norm_a = sqrt(sum(x * x for x in a))
    norm_b = sqrt(sum(y * y for y in b))
    if norm_a == 0 or norm_b == 0:
        return 0.0
    return dot / (norm_a * norm_b)

课堂要求学生手算二维向量，再运行函数验证。重点说明：相似度只是排序信号，不是事实正确概率。

3.4.3 Embedding 客户端的抽象

python
from typing import Protocol


class Embedder(Protocol):
    def embed(self, texts: list[str]) -> list[list[float]]: ...


class CachedEmbedder:
    def __init__(self, inner: Embedder):
        self.inner = inner
        self.cache: dict[str, list[float]] = {}

    def embed(self, texts: list[str]) -> list[list[float]]:
        missing = [text for text in dict.fromkeys(texts) if text not in self.cache]
        if missing:
            vectors = self.inner.embed(missing)
            if len(vectors) != len(missing):
                raise RuntimeError("Embedding 返回数量与输入不一致")
            self.cache.update(zip(missing, vectors))
        return [self.cache[text] for text in texts]

这个接口隔离模型供应商。缓存减少课堂重复调用费用；生产环境需要磁盘缓存、版本键和过期策略。

若平台提供 OpenAI 兼容的 /embeddings 接口，可沿用前置章节的 httpx 封装：

python
import httpx


class CompatibleEmbedder:
    def __init__(self, base_url: str, api_key: str, model: str):
        self.url = f"{base_url.rstrip('/')}/embeddings"
        self.model = model
        self.client = httpx.Client(
            headers={"Authorization": f"Bearer {api_key}"},
            timeout=httpx.Timeout(30.0, connect=10.0),
        )

    def embed(self, texts: list[str]) -> list[list[float]]:
        if not texts:
            return []
        response = self.client.post(self.url, json={"model": self.model, "input": texts})
        response.raise_for_status()
        rows = sorted(response.json()["data"], key=lambda item: item["index"])
        return [row["embedding"] for row in rows]

为什么按 index 排序：批量接口的返回结构带输入序号，客户端不应把“当前恰好有序”当作永久假设。模型名、基础 URL 与密钥从环境变量读取；切换 Embedding 模型后必须重建文档索引。

3.4.4 Chroma 建库与检索

python
import chromadb


class ChromaStore:
    def __init__(self, path: str = "storage/chroma"):
        client = chromadb.PersistentClient(path=path)
        self.collection = client.get_or_create_collection(
            name="enterprise_docs",
            metadata={"hnsw:space": "cosine"},
        )

    def upsert(self, chunks: list[Document], vectors: list[list[float]]) -> None:
        self.collection.upsert(
            ids=[str(c.metadata["chunk_id"]) for c in chunks],
            documents=[c.text for c in chunks],
            metadatas=[c.metadata for c in chunks],
            embeddings=vectors,
        )

    def search(self, query_vector: list[float], top_k: int = 5) -> list[dict]:
        raw = self.collection.query(query_embeddings=[query_vector], n_results=top_k)
        rows = []
        for chunk_id, text, distance, metadata in zip(
            raw["ids"][0], raw["documents"][0], raw["distances"][0], raw["metadatas"][0]
        ):
            rows.append({
                "chunk_id": chunk_id,
                "text": text,
                "score": 1.0 - float(distance),
                "metadata": metadata,
            })
        return rows

注意：不同向量库的 distance 定义不同，不能机械地都写成 1 - distance。课堂使用 cosine 配置时才这样转换，实际项目必须查当前版本文档并用已知向量做一次校验。

06. 3.5 Day 14｜混合检索、融合与重排 ▼

3.5.1 为什么需要多路召回

向量检索擅长语义近似，BM25 擅长型号、编号、专有名词等精确词。工程上常先用两路检索扩大候选集，再融合并重排。

3.5.2 教学版 BM25

BM25 根据词频、逆文档频率和文档长度计算相关度。中文生产系统应使用经过验证的分词器；课堂先用字符二元组，让算法过程不被额外依赖遮住。

python
from collections import Counter
from math import log


def bigrams(text: str) -> list[str]:
    compact = "".join(text.lower().split())
    return [compact[i:i + 2] for i in range(max(0, len(compact) - 1))]


class BM25Retriever:
    def __init__(self, chunks: list[Document], k1: float = 1.5, b: float = 0.75):
        self.chunks = chunks
        self.k1 = k1
        self.b = b
        self.tokens = [bigrams(chunk.text) for chunk in chunks]
        self.avg_len = sum(map(len, self.tokens)) / max(1, len(self.tokens))
        self.df = Counter(term for terms in self.tokens for term in set(terms))

    def search(self, query: str, top_k: int = 10) -> list[dict]:
        query_terms = bigrams(query)
        scored: list[dict] = []
        total = len(self.chunks)
        for chunk, terms in zip(self.chunks, self.tokens):
            frequencies = Counter(terms)
            score = 0.0
            for term in query_terms:
                freq = frequencies[term]
                if freq == 0:
                    continue
                idf = log(1 + (total - self.df[term] + 0.5) / (self.df[term] + 0.5))
                length_norm = self.k1 * (1 - self.b + self.b * len(terms) / max(1, self.avg_len))
                score += idf * (freq * (self.k1 + 1)) / (freq + length_norm)
            if score > 0:
                scored.append({
                    "chunk_id": chunk.metadata["chunk_id"],
                    "text": chunk.text,
                    "metadata": chunk.metadata,
                    "score": score,
                })
        return sorted(scored, key=lambda item: item["score"], reverse=True)[:top_k]

逐行讲解：

  • df 统计“包含某词的文档数”，不是词在全库出现的总次数。
  • idf 让少见词获得更高区分度，因此制度编号和专有名词往往表现较好。
  • length_norm 抑制长文档仅凭出现次数多而占优。
  • 同一查询词若重复出现，教学版会重复累加；生产实现可对查询词去重或使用成熟库，并用评测确认行为。

3.5.3 用 RRF 融合两路排名

Reciprocal Rank Fusion 不要求两路分数处于同一量纲，只使用排名：

$$ RRF(d)=\sum_{r\in R}\frac{1}{k+rank_r(d)} $$

python
from collections import defaultdict


def rrf_fusion(
    ranked_lists: list[list[dict]],
    limit: int = 10,
    k: int = 60,
) -> list[dict]:
    scores: dict[str, float] = defaultdict(float)
    by_id: dict[str, dict] = {}
    for results in ranked_lists:
        for rank, item in enumerate(results, start=1):
            chunk_id = item["chunk_id"]
            scores[chunk_id] += 1.0 / (k + rank)
            by_id[chunk_id] = item

    ordered_ids = sorted(scores, key=scores.get, reverse=True)[:limit]
    return [{**by_id[cid], "fusion_score": scores[cid]} for cid in ordered_ids]

逐行讲解：

  • scores 累加同一文档在不同列表中的排名贡献。
  • by_id 保留原始文本和元数据。
  • 同时被两路排在前面的块自然获得较高融合分。
  • k 越大，头部与尾部名次差异越平滑。它需要用固定评测集调参。

3.5.4 轻量重排器接口

python
from typing import Callable


RerankFn = Callable[[str, list[str]], list[float]]


def rerank(query: str, candidates: list[dict], score_fn: RerankFn, top_n: int = 5) -> list[dict]:
    texts = [item["text"] for item in candidates]
    scores = score_fn(query, texts)
    if len(scores) != len(candidates):
        raise RuntimeError("重排分数数量不匹配")
    enriched = [{**item, "rerank_score": float(score)} for item, score in zip(candidates, scores)]
    return sorted(enriched, key=lambda item: item["rerank_score"], reverse=True)[:top_n]

重排模型只处理较小候选集，通常比全库逐条精排便宜。课堂先召回 20 条，再重排到 5 条，并比较延迟与 Recall@5 / MRR。

3.5.5 评测检索而不是先看最终答案

python
def recall_at_k(retrieved_ids: list[str], relevant_ids: set[str], k: int) -> float:
    if not relevant_ids:
        raise ValueError("relevant_ids 不能为空")
    hits = len(set(retrieved_ids[:k]) & relevant_ids)
    return hits / len(relevant_ids)


def reciprocal_rank(retrieved_ids: list[str], relevant_ids: set[str]) -> float:
    for rank, chunk_id in enumerate(retrieved_ids, start=1):
        if chunk_id in relevant_ids:
            return 1.0 / rank
    return 0.0

教学重点：若检索证据都错了，单独调整生成提示词通常治标不治本。先分层评测检索，再评测生成。

07. 3.6 Day 15｜带引用生成、拒答与 RAG 评测 ▼

3.6.1 证据上下文组装

python
def build_context(results: list[dict], max_chars: int = 6000) -> tuple[str, list[dict]]:
    blocks: list[str] = []
    citations: list[dict] = []
    used = 0
    for index, item in enumerate(results, start=1):
        meta = item["metadata"]
        label = f"S{index}"
        block = f"[{label}] 来源={meta.get('source')} 页码={meta.get('page', '无')}\n{item['text']}"
        if used + len(block) > max_chars:
            break
        blocks.append(block)
        citations.append({"label": label, "chunk_id": item["chunk_id"], **meta})
        used += len(block)
    return "\n\n".join(blocks), citations

3.6.2 受约束的生成提示词

python
SYSTEM_PROMPT = """你是企业制度问答助手。
只能依据给定证据回答，不得把常识当作企业制度。
每个关键结论后标注证据编号，例如 [S1]。

若证据互相冲突，列出冲突来源，不自行选择其中一个。
"""


def build_messages(question: str, context: str) -> list[dict[str, str]]:
    return [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": f"证据：\n{context}\n\n问题：{question}"},
    ]

3.6.3 检索前置拒答

python
def should_abstain(results: list[dict], min_score: float) -> tuple[bool, str]:
    if not results:
        return True, "没有检索到任何证据"
    best = max(float(item.get("rerank_score", item.get("score", 0.0))) for item in results)
    if best < min_score:
        return True, f"最高相关分 {best:.3f} 低于阈值 {min_score:.3f}"
    return False, "证据达到生成条件"

阈值不能凭感觉确定。使用一组“可回答”和“不可回答”问题扫描多个阈值，观察错误回答率与错误拒答率，再选择业务可接受点。

import re


def validate_citations(answer: str, allowed_labels: set[str]) -> list[str]:
    used = set(re.findall(r"\[(S\d+)\]", answer))
    return sorted(used - allowed_labels)

这个检查只能发现“引用了不存在的编号”，不能证明引用内容支持结论。后者需要人工审核或额外的蕴含判定。

08. 3.7 Day 16｜章节实战：企业知识库问答系统 ▼

3.7.1 完整管线

python
from dataclasses import dataclass


@dataclass
class RagAnswer:
    answer: str
    citations: list[dict]
    retrieved: list[dict]
    abstained: bool
    reason: str


class RagPipeline:
    def __init__(self, retriever, llm, min_score: float = 0.35):
        self.retriever = retriever
        self.llm = llm
        self.min_score = min_score

    def answer(self, question: str) -> RagAnswer:
        question = question.strip()
        if not question:
            raise ValueError("问题不能为空")

        results = self.retriever.search(question, top_k=5)
        abstain, reason = should_abstain(results, self.min_score)
        if abstain:
            return RagAnswer(
                answer="当前知识库中没有足够依据。",
                citations=[], retrieved=results, abstained=True, reason=reason,
            )

        context, citations = build_context(results)
        answer = self.llm.chat(build_messages(question, context))
        invalid = validate_citations(answer, {c["label"] for c in citations})
        if invalid:
            raise RuntimeError(f"模型生成了无效引用: {invalid}")
        return RagAnswer(answer, citations, results, False, reason)

代码走读顺序：

  1. 在系统边界校验空问题。
  2. 检索器内部执行混合召回与重排。
  3. 低置信结果在调用 LLM 前拒答，节省成本并减少幻觉。
  4. 上下文和引用使用同一次遍历生成，避免编号错位。
  5. 返回检索结果用于调试，生产接口可按权限决定是否暴露全文。

3.7.2 FastAPI 接口骨架

python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI(title="Enterprise Knowledge API")


class AskRequest(BaseModel):
    question: str = Field(min_length=1, max_length=1000)


@app.post("/ask")
def ask(payload: AskRequest):
    try:
        result = pipeline.answer(payload.question)
        return {
            "answer": result.answer,
            "citations": result.citations,
            "abstained": result.abstained,
            "reason": result.reason,

    except ValueError as exc:

    except Exception as exc:
        raise HTTPException(status_code=500, detail="知识库服务暂时不可用") from exc
