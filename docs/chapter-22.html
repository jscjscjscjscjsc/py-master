02. 22.1 HTML：页面的骨架 ▼

22.1.1 概念认知：HTML 是什么

HTML（超文本标记语言） 用标签描述页面的"结构"：这是标题、这是段落、这是按钮。它不是编程语言（没有逻辑），是"标记语言"。

22.1.2 语法掌握：页面基本结构

代码案例 22.1：最小完整页面（✅ 正确）

html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的第一个页面</title>
</head>
<body>
    <h1>你好，Web！</h1>
    <p>这是第一段文字。</p>
</body>
</html>

讲解：

  • <!DOCTYPE html>：告诉浏览器"这是 HTML5"；
  • <head>：页面"配置区"（编码、标题、样式引用）；
  • <body>：页面"内容区"（用户看到的一切）；
  • 标签成对出现（<h1> 开始、</h1> 结束）——忘记闭合标签是新手最常见错误。

22.1.3 语法掌握：常用标签

代码案例 22.2：常用标签（✅ 正确）

html

    <li>另一项</li>
</ul>

    <li>有序第一项</li>

讲解：先认识标签长什么样（<标签 属性="值">内容</标签>），不需要背全——用的时候查，查多了自然记住。

22.1.4 语法掌握：语义化标签

代码案例 22.3：页面分区（✅ 正确）

html

    <header>页面头部（标题、导航）</header>
    <nav>导航链接</nav>
    <main>
        <article>主要内容</article>
        <aside>侧边栏</aside>

03. 22.2 CSS：页面的样式 ▼

22.2.1 概念认知：CSS 是什么

CSS（层叠样式表） 控制页面"长什么样"：颜色、大小、间距、布局。写法：选择器 { 属性: 值; }。

22.2.2 语法掌握：选择器与盒模型

代码案例 22.4：CSS 基础（✅ 正确）

html
<style>
    /* 标签选择器：所有 h1 */
    h1 { color: #2563eb; }

    /* 类选择器：class="card" 的元素 */
    .card {
        border: 1px solid #ddd;
        padding: 16px;      /* 内边距：内容与边框的距离 */
        margin: 12px;       /* 外边距：卡片与周围的距离 */
        border-radius: 8px;
    }

    /* id 选择器：id="header" 的元素 */
    #header { background: #f0f0f0; }
</style>

<div class="card">卡片内容</div>

原理探秘：盒模型

每个 HTML 元素都是一个"盒子"，从外到内四层：margin（外边距）→ border（边框）→ padding（内边距）→ content（内容）。

调间距时先想清楚：是"盒子之间的距离"（margin）还是"内容与边框的距离"（padding）？90% 的"布局对不齐"都是这两个搞混了。

22.2.3 语法掌握：Flex 布局入门

代码案例 22.5：Flex 水平布局（✅ 正确）

html
<style>
    .row {
        display: flex;              /* 开启弹性布局 */
        gap: 12px;                  /* 子元素间距 */
        justify-content: center;    /* 水平居中 */
    }
    .box { width: 100px; height: 100px; background: #38bdf8; }
</style>

<div class="row">
    <div class="box"></div>
    <div class="box"></div>
    <div class="box"></div>
</div>

讲解：display: flex 让子元素横着排；justify-content 控制水平对齐（center 居中、space-between 两端对齐）。最终项目的数据大屏/卡片布局会大量用到 flex（第 33 章）。

04. 22.3 JavaScript：页面的行为 ▼

22.3.1 概念认知：JS 是什么

JavaScript 让页面"动起来"：点击按钮、动态加内容、请求数据。注意：它和 Python 语法不同（但编程思想完全一样）——你学的变量、循环、函数、对象，在 JS 里都有对应。

22.3.2 语法掌握：JS 基础（对照 Python 学）

代码案例 22.6：JS 基础（✅ 正确，Node 实测过）

html
<script>
    // 变量：let 可变、const 常量
    let name = "张三";
    const age = 19;

    // 函数
    function greet(n) {
        return `你好，${n}！`;
    }

    // 模板字符串（相当于 Python 的 f-string）
    console.log(`${name} 今年 ${age} 岁`);

    // 数组与遍历
    const scores = [88, 92, 76];
    let total = 0;
    for (const s of scores) {
        total += s;
    }

    // 对象（相当于 Python 的字典）
    const student = { name: "张三", scores: [88, 92] };
    console.log(student.name, student.scores[0]);
</script>

讲解：console.log() 相当于 Python 的 print()（在浏览器开发者工具的控制台显示）。你已经会的编程思维，换个语法就是 JS。

22.3.3 语法掌握：DOM 与事件

DOM（文档对象模型） = 浏览器把 HTML 变成一棵"可操作的树"，JS 通过它读写页面。

代码案例 22.7：点击按钮修改页面（✅ 正确）

html
<p id="message">原始文字</p>
<button id="btn">点我</button>

<script>
    const btn = document.getElementById("btn");
    const msg = document.getElementById("message");

    btn.addEventListener("click", function () {
        msg.textContent = "按钮被点击了！";
        msg.style.color = "#2563eb";
    });
</script>

讲解：

  • document.getElementById("btn")：从 DOM 里找到元素（第 5 章"按名字找"——JS 版字典查询）；
  • addEventListener("click", 函数)：注册事件处理——点击时执行函数（第 7 章"回调函数"的实战！）；
  • msg.textContent = ...：修改元素内容。

交叉验证：你的 Python 知识怎么迁移到 JS？

概念PythonJavaScript
输出print(x)console.log(x)
字典/对象d["name"]obj.name
字符串模板f"{x}"` ${x} `
列表/数组[1, 2][1, 2]
回调sorted(key=fn)btn.addEventListener("click", fn)

讲解：编程思想是通用的，语法只是换皮——这是你学完 Python 后学第二门语言最大的红利。

05. 22.4 fetch：前端调后端 ▼

22.4.1 语法掌握：fetch 与 JSON

代码案例 22.8：调用 API 并渲染（✅ 正确）

html
<ul id="list"></ul>

<script>
    // fetch 返回一个 Promise，用 async/await 等待结果（第 13 章异步思想！）
    async function loadStudents() {
        const resp = await fetch("/api/students");
        const students = await resp.json();   // 解析 JSON

        const list = document.getElementById("list");
        for (const s of students) {
            const li = document.createElement("li");
            li.textContent = `${s.name}: ${s.score}`;
            list.appendChild(li);
        }
    }

    loadStudents();
</script>

讲解：

  • fetch("/api/students")：发 HTTP 请求（第 13 章 requests 的前端版）；
  • await resp.json()：等响应并解析 JSON（async/await 你在第 13 章学过！）；
  • createElement / appendChild：动态往页面加元素；
  • 前端调用后端的完整链路：前端 fetch → 后端处理 → 返回 JSON → 前端渲染——这就是前后端分离的数据流（第 21 章）。

微任务卡（M2 · 讲解卡 · L3）：把 fetch 代码发给 AI："请解释 async/await 在这里的作用，为什么需要等待？和 Python 的 asyncio 有什么相似？"一句话记录理解。

22.4.2 语法掌握：开发者工具调试

  1. 在页面按 F12（或右键 → 检查）打开开发者工具；
  2. Elements：查看/修改 HTML 和 CSS（改完即时生效，方便试样式）；
  3. Console：看 console.log 输出和报错；
  4. Network：看每个请求的状态码、响应内容——前后端联调必看（第 33 章）。

交叉验证：前端报错的排查顺序

  1. Console 有没有红字？（语法错误/类型错误）
  2. Network 里请求的状态码是多少？（404 = 路径错、500 = 后端错、200 = 请求正常）
  3. 返回的 JSON 结构和代码期望的一致吗？（字段名对不对）

07. 22.6 本章 Debug 四件套 ▼

问题 1：标签没闭合

问题代码：

html
<p>第一段
<p>第二段

实际表现：页面显示错乱（段落嵌套、样式错位）。

提示：<p> 的结束标签在哪？

讲解：标签必须成对闭合（<p>...</p>）。浏览器对错误很宽容，但宽容的结果是"显示得莫名其妙"。养成"写开始标签立刻写结束标签"的习惯。

问题 2：CSS 不生效

问题代码：

html
<style>
    .Card { color: red; }
</style>
<div class="card">文字</div>

实际表现：文字不是红色。

提示：选择器里的类名和 HTML 里的 class 一致吗？大小写呢？

讲解：.Card 和 class="card" 不匹配——类名严格区分大小写。对照检查选择器与 HTML 的 class 是否完全一致。

问题 3：JS 报错 undefined

问题代码：

js
const student = { name: "张三" };
console.log(student.score);

实际表现：控制台输出 undefined，后续用到 score 的地方出错。

提示：对象里没有 score 这个键，读取返回什么？（对照第 6 章 KeyError 的 JS 版本）

讲解：JS 读取不存在的属性返回 undefined（不报错）——比 Python 的 KeyError 更"安静"，所以更危险。假设数据可能缺字段，用前先判断（if (student.score !== undefined)）。

问题 4：fetch 的 URL 404

问题代码：

js
const resp = await fetch("/api/students");   // 后端实际是 /api/student

实际表现：Network 面板显示 404，页面空白。

提示：请求地址和后端路由一致吗？Network 面板怎么查？

讲解：404 先查 URL 拼写（单复数、大小写）；前端和后端的路径必须严格一致——这就是第 21 章"接口契约"的日常维护。

09. 22.8 本章小结与知识树 ▼

知识树：

前端基础：HTML / CSS / JavaScript
├── HTML（骨架）：标签成对闭合；head 配置 / body 内容
│   ├── 常用：h1-h6 / p / ul / ol / a / img / table / form
│   └── 语义化：header / nav / main / article / aside / footer
├── CSS（样式）：选择器 { 属性: 值 }
│   ├── 选择器：标签 / .类 / #id
│   ├── 盒模型：margin（外）→ border → padding（内）→ content
│   └── Flex：display:flex + gap + justify-content
├── JavaScript（行为）
│   ├── 与 Python 对照：console.log / 对象 / 模板字符串 / 数组
│   ├── DOM：document.getElementById → 修改 textContent / style
│   └── 事件：addEventListener("click", 回调函数)
├── fetch：await fetch(url) → await resp.json() → 渲染 DOM
│   └── 调试：F12 → Elements / Console / Network（404 先查 URL）
└── 综合：个人名片页 = HTML + CSS + JS 三件套

必须记住的 5 件事：

  1. 标签成对闭合；<head> 配置、<body> 内容；
  2. 盒模型：margin 管"盒子外"，padding 管"盒子内"；
  3. console.log 相当于 JS 的 print，调试从 F12 开始；
  4. fetch = 前端的 requests；404 先查 URL；
  5. 你的 Python 思维可以直接迁移到 JS——思想通用，语法换皮。
