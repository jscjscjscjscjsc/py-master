01. 算术运算符 ▼

算术运算符一览

运算符说明示例结果
+加法3 + 25
-减法3 - 21
*乘法3 * 26
/除法（浮点）7 / 23.5
//整除7 // 23
%取余（取模）7 % 21
**幂运算2 ** 38

重点辨析：/ vs //

print(7 / 2)    # 3.5（普通除法，总是返回 float）
print(7 // 2)   # 3（整除，向下取整，丢弃小数部分）
print(-7 // 2)  # -4（注意！向下取整：-3.5 → -4，不是 -3）
print(int(-7 / 2))  # -3（int() 是向零截断，与 // 不同！）

% 取模的妙用

# 判断奇偶
num = 7
if num % 2 == 0:
    print("偶数")
else:
    print("奇数")

# 循环数组
colors = ["红", "绿", "蓝"]
for i in range(10):
    print(colors[i % 3])  # 红绿蓝红绿蓝红绿蓝红

# 获取个位数
print(1234 % 10)   # 4
print(1234 % 100)  # 34

** 幂运算

print(2 ** 10)    # 1024（2的10次方）
print(4 ** 0.5)   # 2.0（开平方根）
print(8 ** (1/3)) # 2.0（开立方根）

02. 比较运算符 ▼

比较运算符

运算符说明示例
==等于5 == 5 → True
!=不等于5 != 3 → True
>大于5 > 3 → True
<小于5 < 3 → False
>=大于等于5 >= 5 → True
<=小于等于5 <= 3 → False

比较运算符返回布尔值，常用于条件判断和循环中。

== vs is（重要！）

# == 比较值是否相等
# is 比较是否是同一个对象（同一内存地址）
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)  # True（值相同）
print(a is b)  # False（不同的列表对象）

# 对于小整数和短字符串，Python 有缓存机制
x = 256
y = 256
print(x is y)  # True（小整数被缓存）

x = 257
y = 257
print(x is y)  # 可能是 False（大整数不一定缓存）

链式比较（Python 特色语法）

# Python 支持链式比较！
age = 25
# 等价于 age >= 18 and age <= 60
if 18 <= age <= 60:
    print("成年人")

x = 10
print(1 < x < 20)  # True（等价于 1 < x and x < 20）
print(1 < x > 5)   # True（等价于 1 < x and x > 5，但这样写容易混淆）

03. 逻辑运算符 ▼

逻辑运算符

运算符说明示例
and与（两边都为 True 才返回 True）True and False → False
or或（一边为 True 就返回 True）True or False → True
not非（取反）not True → False

短路求值（Short-circuit Evaluation）

Python 的逻辑运算会在能确定结果时立即停止：

# and: 第一个为 False 就不看第二个
def expensive_check():
    print("执行了耗时检查")
    return True

False and expensive_check()  # "执行了耗时检查"不会被打印，因为 False 已经确定了

# or: 第一个为 True 就不看第二个
True or expensive_check()  # "执行了耗时检查"不会被打印，因为 True 已经确定了

短路求值的实用技巧

# 安全访问：如果 name 非空才访问 .upper()
name = "" or "默认名称"
print(name)  # "默认名称"

# 防止除零
b = 0
result = b != 0 and (10 / b)  # False，不会执行除法
print(result)  # False

# 条件赋值
user_input = input("输入名字: ")
display_name = user_input or "匿名用户"  # 如果 user_input 为空就用默认值
print(display_name)

逻辑运算 vs 位运算

# 逻辑运算（操作布尔值）
print(True and False)  # False

# 位运算（操作整数二进制位）—— 先了解一下，后面会详细学
print(5 & 3)   # 1（按位与：101 & 011 = 001）
print(5 | 3)   # 7（按位或：101 | 011 = 111）
print(~5)      # -6（按位取反）
print(5 ^ 3)   # 6（按位异或：101 ^ 011 = 110）

04. 赋值运算符 ▼

赋值运算符

运算符等价于
x += 3x = x + 3
x -= 3x = x - 3
x *= 3x = x * 3
x /= 3x = x / 3
x //= 3x = x // 3
x %= 3x = x % 3
x **= 3x = x ** 3

多重赋值与元组解包

# 同时赋值
a = b = c = 100       # 三个变量都是 100

# 元组解包（最优雅的 Python 特性之一）
x, y = 10, 20         # x=10, y=20
x, y = y, x           # 交换变量值！不需要临时变量

# 多返回值接住
def get_user():
    return "张三", 25, "北京"
name, age, city = get_user()  # 一次性解包
print(f"{name}，{age}岁，来自{city}")

# 用 * 收集剩余
first, *rest = [1, 2, 3, 4, 5]
print(first)  # 1
print(rest)   # [2, 3, 4, 5]

*head, last = [1, 2, 3, 4, 5]
print(head)  # [1, 2, 3, 4]
print(last)  # 5

海象运算符 :=（Python 3.8+）

# 在表达式中赋值并立即使用
# 传统写法
n = len(data)
if n > 10:
    print(f"数据有{n}条")

# 海象运算符写法
if (n := len(data)) > 10:
    print(f"数据有{n}条")

# 在 while 中特别有用
while (line := file.readline()):
    process(line)

运算符优先级（从高到低）

优先级运算符
最高() 括号
** 幂运算
-x（一元负号）
* / // %
+ -
< <= > >= == !=
not
and
最低or

记不住？加括号！ (a + b) * c 比 a + b * c 更清晰。
