01. Python 是什么？ ▼

Python 的起源

Python 由荷兰程序员 Guido van Rossum（吉多·范罗苏姆）于 1989 年圣诞节期间开始设计，1991 年发布第一个版本。Guido 当时在荷兰数学与计算机科学研究中心（CWI）工作，他希望创造一种语法简洁、易于阅读的脚本语言。

为什么叫 Python？

名字来源于 Guido 喜爱的英国喜剧团体 Monty Python（蒙提·派森），而不是蟒蛇。这也是为什么 Python 官方文档中经常出现 Monty Python 的梗。

Python 的设计哲学

  • 优美胜于丑陋（Beautiful is better than ugly）
  • 明了胜于晦涩（Explicit is better than implicit）
  • 简洁胜于复杂（Simple is better than complex）
  • 可读性很重要（Readability counts）

在 Python 解释器中输入 import this 可以查看完整的 Python 之禅（The Zen of Python）。

Python 的特点

  • 简洁优雅：语法接近自然语言，代码可读性极高，强制缩进使代码结构清晰
  • 解释型语言：不需要编译，逐行执行方便调试（实际上 Python 会先将源码编译为字节码 .pyc 再执行）
  • 动态类型：变量不需要声明类型，运行时可改变类型，开发效率高
  • 跨平台：Windows、macOS、Linux 都能运行，一套代码多平台复用
  • 丰富的库：标准库就已非常强大，更有海量第三方库（PyPI 上超过 40 万个包），覆盖 AI、Web、数据分析等领域
  • 开源免费：PSF（Python 软件基金会）维护，社区活跃

Python 2 vs Python 3

对比项Python 2Python 3
printprint "hello"（语句）print("hello")（函数）
整数除法3/2 = 1（截断）3/2 = 1.5（浮点）
Unicode默认 ASCII，需声明默认 UTF-8
状态2020年已停止维护当前主流版本

重要：初学者应学习 Python 3！Python 2 已不再维护。

Python 的应用领域

  • 人工智能与机器学习（TensorFlow, PyTorch, scikit-learn）
  • 数据科学与分析（Pandas, NumPy, Matplotlib）
  • Web 开发（Django, Flask, FastAPI）
  • 自动化运维与测试（脚本化重复任务）
  • 网络爬虫（requests + BeautifulSoup / Scrapy）
  • 游戏开发（Pygame）
  • 桌面应用（PyQt, Tkinter）

02. Python 的安装 ▼

Windows 安装步骤

  1. 访问 Python 官网 python.org
  2. 点击 Downloads，选择 Windows 版本（推荐 3.10+）
  3. 下载安装包
  4. 重要：勾选「Add Python to PATH」复选框！ 这让你可以在命令行任意位置运行 Python
  5. 点击 Install Now 完成安装
  6. 打开命令提示符，输入 python --version 验证
C:\Users\你的用户名> python --version
Python 3.12.3

macOS 安装

macOS 通常自带 Python 2.x（已废弃），建议使用 Homebrew 安装 Python 3：

brew install python3

或者从 python.org 下载 macOS 安装包直接安装。

Linux 安装

# Ubuntu/Debian
sudo apt update && sudo apt install python3

# CentOS/RHEL
sudo yum install python3

PATH 环境变量

「Add Python to PATH」的作用是让系统知道 Python 在哪。如果忘记勾选：

  1. 搜索「编辑系统环境变量」
  2. 点击「环境变量」→ 在 Path 中添加 Python 安装目录（如 C:\Python312）和 Scripts 目录（如 C:\Python312\Scripts）

pip 包管理器

安装 Python 时会自动安装 pip，它是 Python 的包管理器，用于安装第三方库：

pip install 库名     # 安装库
pip list             # 查看已安装的库
pip uninstall 库名   # 卸载库

03. 第一个 Python 程序 ▼

Hello, World!

创建你的第一个 Python 程序：

print("Hello, World!")

运行后屏幕上显示 Hello, World!。

运行 Python 代码的三种方式

方式说明适用场景
交互模式终端输入 python，逐行输入代码立即执行快速测试、临时计算
脚本模式代码写入 .py 文件，用 python 文件名.py 运行正式项目、保存代码
IDE 运行在 VS Code / PyCharm 中按 F5 或点击运行按钮日常开发最常用

交互模式详解

$ python
>>> 2 + 3
5
>>> print("Hello")
Hello
>>> exit()  # 退出交互模式

交互模式中 >>> 是提示符，表示 Python 已准备好接收指令。

Python 脚本结构

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""这是脚本的文档字符串，描述脚本功能"""

# 导入模块
import math

# 定义函数
def greet(name):
    return f"你好，{name}！"

# 主程序入口
if __name__ == "__main__":
    print(greet("世界"))
    print(f"圆周率是 {math.pi}")

if __name__ == "__main__" 是 Python 的常见模式，表示「当这个文件被直接运行时才执行以下代码」。

练习 1
Python 是编译型语言还是解释型语言？
📝 答案解析
Python 是解释型语言。代码在运行时由 Python 解释器逐行翻译成机器码并执行，不需要预先编译。不过实际上 Python 会先将源码编译成字节码（.pyc），然后再由虚拟机执行，但从使用角度看它属于解释型语言。

04. IDE 与代码编辑器 ▼

常用开发工具对比

工具特点价格适合人群
IDLEPython 自带，简单轻量，无需安装免费初学者快速体验
VS Code微软出品，免费开源，插件市场丰富，启动快免费绝大多数开发者（推荐！）
PyCharmJetBrains 出品，专业 Python IDE，智能补全、重构社区版免费专业 Python 开发者
Jupyter Notebook浏览器中交互编程，代码+文档+图表一体免费数据科学家、教学
Thonny专为 Python 初学者设计，简单直观免费零基础入门

推荐：VS Code 配置 Python

  1. 安装 VS Code（code.visualstudio.com）
  2. 打开 VS Code → 左侧扩展图标（Ctrl+Shift+X）
  3. 搜索并安装 Python 扩展（Microsoft 官方）
  4. 还可以安装：Pylance（智能提示）、Python Debugger（调试）
  5. 创建一个 .py 文件，开始写代码

写代码的基本流程

  1. 创建文件：新建一个 .py 文件
  2. 编写代码：在编辑器中输入代码
  3. 运行代码：按 F5 或在终端中运行
  4. 查看结果：在终端中查看输出
  5. 修改调试：根据报错信息修改代码

小建议：新手从 IDLE 或 Thonny 开始，熟悉后换 VS Code。不要一上来就配 PyCharm，太复杂反而劝退。
